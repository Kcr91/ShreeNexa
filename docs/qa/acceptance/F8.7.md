# F8.7 Acceptance Contract — Visual Stock Strategy Builder Mapping Exactly to StrategyIR Nodes

## Feature

Interactive visual stock strategy builder UI mapping directly to backend StrategyIR AST nodes, with lossless UI->IR->UI round-trip decompilation and execution through the strategy compiler and evaluator.

## Scope decisions recorded before implementation

- **Exact 1-to-1 Mapping with Canonical StrategyIR (Spec §10.1 & §10.2)**:
  - Supports signal condition nodes: `CrossOver`, `CrossUnder`, `IndicatorCompare`, `And`, `Or`, `Not`, `TimeWindow`, `PriceLevelBreak`.
  - Supports indicator definitions: `EMA`, `SMA`, `RSI`, `MACD`, `VWAP`, `ATR`, `SuperTrend`, `BollingerBands`.
  - Supports universe selectors (`index`, `symbols`), timeframe, session windows, position sizing, and risk rules.
- **Lossless UI->IR->UI Round-Trip**:
  - `compileVisualToStrategyIR(state)` converts visual nodes into valid canonical StrategyIR.
  - `decompileStrategyIRToVisual(ir)` reconstructs the visual builder state from any valid stock StrategyIR without losing logical intent.
- **Backend Schema Validation & Evaluator Execution**:
  - `POST /api/v1/strategy/validate` parses and validates StrategyIR using Pydantic `StrategyIR` schema.
  - Produced IR compiles and runs successfully through `VectorStrategyCompiler` and `IncrementalStrategyEngine` (G2 tests).
- **Frontend UI Surfaces**:
  - `StrategyBuilderWidget.tsx` includes:
    - Visual indicator cards and rule block editor (Entry / Exit / Risk).
    - Live StrategyIR JSON editor & Export/Import modal.
    - Lossless round-trip import and visual state reconstruction.
    - Live validation badge (`🟢 Valid StrategyIR`).

## Required deliverables

1. `frontend/src/strategybuilder/canonical.ts` — Lossless compiler (`compileVisualToCanonicalIR`) and decompiler (`decompileCanonicalIRToVisual`).
2. `frontend/src/strategybuilder/canonical.test.ts` — Round-trip tests verifying `UI -> IR -> UI` equivalence.
3. `backend/app/api/strategy_ir.py` — REST API router for validation, schema export, and template generation.
4. `backend/tests/unit/test_visual_strategy_ir_roundtrip.py` — Python unit tests verifying builder-generated StrategyIR compiles and executes in vector/incremental engines.
5. `frontend/src/widgets/builtin/StrategyBuilderWidget.tsx` — Visual builder UI with canonical StrategyIR export/import.
6. `frontend/src/widgets/builtin/StrategyBuilderWidget.test.tsx` — Frontend tests for visual editing and round-trip.
7. `docs/qa/acceptance/F8.7.md` — Acceptance contract.
