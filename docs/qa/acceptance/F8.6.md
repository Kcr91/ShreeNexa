# F8.6 Acceptance Contract — Net Greeks Plus Dhan Margin Adapter and Reconciliation

## Feature

Dhan margin adapter and multi-leg basket margin calculator estimating SPAN margin, exposure margin, premium margin, gross margin, net required margin, and hedging relief benefits for multi-leg option strategies, with strict handling for unavailable broker states.

## Scope decisions recorded before implementation

- **Margin Composition & Hedging Benefit (Spec §9.2 & §11.6)**:
  - Long Options: Pure premium outlay ($\text{Premium Margin} = Q \cdot P_0$, $\text{SPAN} = 0$, $\text{Exposure} = 0$).
  - Short Naked Options: Standard exchange SPAN ($\approx 10.5\%-12\%$ contract value) + Exposure ($\approx 2\%-3.5\%$ contract value).
  - Hedged Defined-Risk Spreads (Bull Call Spread, Bear Put Spread, Iron Condor, Iron Butterfly):
    - Caps required margin to $\max(\text{Defined Max Loss}, \text{Min Spread Margin Buffer})$.
    - Computes Hedging Benefit Margin = $\text{Gross Unhedged Margin} - \text{Net Required Margin}$.
- **Explicit Unavailable Handling**:
  - If broker margin calculation fails, broker API is offline, or quote data is missing, the system returns `is_available: False` with `unreliable_reason = "..."`.
  - **Invariance Rule**: Unavailable margin is explicit and NEVER quietly reported as zero ($0.0$).
- **Reconciliation with Dhan Calculator**:
  - Verified against recorded Dhan sample responses for NIFTY & BANKNIFTY single legs, vertical spreads, and 4-leg condors.
- **REST API & UI Surfaces**:
  - `POST /api/v1/options/margin/calculate` returns `BasketMarginResult`.
  - `OptionStrategyBuilderWidget.tsx` surfaces live margin card showing Required Margin, Hedging Benefit, and SPAN/Exposure breakdown with offline/unavailable warning badge.

## Required deliverables
