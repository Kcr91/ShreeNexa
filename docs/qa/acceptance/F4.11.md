# F4.11 Acceptance Contract — Audio/Visual Notification and Alert Manager with Toast Stack and Risk Event Banners

## Feature

Enterprise terminal notification system featuring floating toast notification stacks, synthesized multi-tone Web Audio chimes (Order Fill, Order Reject, Margin Call, Risk Breach), top risk event banners, sound mute/unmute controls, and an audit-trailed Alerts Log widget.

## Scope decisions recorded before implementation

- **Alert Severity & Categorization**:
  - Severities: `INFO`, `SUCCESS`, `WARNING`, `CRITICAL`, `RISK_BREACH`.
  - Categories: `ORDER_FILL`, `ORDER_REJECT`, `MARGIN_CALL`, `RISK_BREACH`, `PRICE_ALERT`, `SYSTEM`.
- **Synthesized Web Audio Engine**:
  - Pure Web Audio API tone synthesis (no external audio assets required) with distinct tonal signatures for order execution, rejections, margin alerts, and risk breaches.
  - Sound toggle with volume controls and silent headless fallback in test environments.
- **Visual Alert Presentations**:
  - Floating auto-dismissing toast stack on bottom-right.
  - Persistent red warning banner on top for severe risk breaches until acknowledged.
- **Alerts Log Widget**:
  - Filterable audit table displaying timestamps, category, severity badges, read/unread status, and sound test action.
  - Registered in `widgetRegistry` under category `analytics`.

## Required deliverables

1. `frontend/src/notifications/types.ts` — Type definitions for alerts, toasts, severities, and audio settings.
2. `frontend/src/notifications/audio.ts` — Web Audio synthesizer generating tone sequences.
3. `frontend/src/notifications/NotificationContext.tsx` — Context provider and `useNotifications` hook.
4. `frontend/src/notifications/ToastContainer.tsx` — Visual toast stack and risk banner component.
5. `frontend/src/widgets/builtin/AlertsLogWidget.tsx` — Audit log widget with sound controls and filter tabs.
6. `frontend/src/widgets/builtin/index.ts` — Registration of `alertsLogDefinition`.
7. `frontend/src/notifications/audio.test.ts`, `notifications.test.ts`, and `AlertsLogWidget.test.tsx` — Unit tests.
8. `docs/qa/acceptance/F4.11.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Toast stack and severity styling
- Triggering an alert pushes a toast item to the stack with color-coded severity icon and auto-dismiss timer.

### B2 — Web Audio synthesizer tone triggers
- Raising an `ORDER_FILL` or `RISK_BREACH` alert invokes the synthesized tone generator when audio is enabled and respects mute toggle.

### B3 — Alerts log filtering and management
- Displays notification audit history, filters by severity, marks items as read, and clears history.
