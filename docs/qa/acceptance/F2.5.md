# F2.5 Acceptance Contract — Versioned StrategyIR Pydantic Schema and JSON Schema Export

## Feature

Versioned Pydantic StrategyIR specification, recursive signal node schemas, universe selectors, option legs, and JSON Schema exporter for strategy definitions across backtesting, paper trading, live trading, and AI strategy generation.

## Scope decisions recorded before implementation

- **Versioned Pydantic Models**:
  - `StrategyIR` (v1) top-level model capturing:
    - `ir_version: int = 1`
    - `name: str`
    - `kind: StrategyKind` (`stock`, `option`, `investing`, `composite`)
    - `horizon: StrategyHorizon` (`intraday`, `swing`, `positional`, `investing` — selecting grading band profile per §10.4.3)
    - `strategy_type: StrategyType` (`trend_following`, `swing_trading`, `mean_reversion`, `option_selling`, `other` — selecting win-rate band per §10.4.4)
    - `universe: UniverseSelector` (`static`, `watchlist`, `screener`, `index`, `option_legs`)
    - `timeframe: str` (e.g., `1m`, `5m`, `15m`, `1d`)
    - `session: SessionConfig` (e.g. `segment="NSE_EQ"`)
    - `indicators: dict[str, IndicatorDef]`
    - `entries: list[EntryRule]`
    - `exits: list[ExitRule]`
    - `sizing: SizingRule`
    - `risk: RiskRule`
- **Signal Grammar & Node Vocabulary**:
  - Full recursive signal hierarchy: `And`, `Or`, `Not`, `PriceLevelBreak`, `Sequence`, `TimeWindow`, `IndicatorCompare`, `CrossOver`, `CrossUnder`, `PctChange`, `Persist`, `StrategySignal`, `Regime`, `CustomPython`.
- **Option Leg & Strike Selectors**:
  - `OptionLegDef` with `ATMStrike`, `DeltaStrike`, `PremiumStrike`, `AbsoluteStrike`.
- **JSON Schema Exporter & Migration Protocol**:
  - `export_strategy_ir_json_schema()` returning JSON Schema dictionary conforming to Draft-07/2020-12.
  - `migrate_strategy_ir(data, target_version)` for schema evolution.

## Required deliverables

1. `backend/app/strategy/ir.py` — Complete Pydantic models for StrategyIR and components.
2. `backend/app/strategy/migration.py` — Migration functions across IR versions.
3. `backend/app/strategy/__init__.py` — Strategy package exports.
4. `docs/qa/acceptance/F2.5.md` — Acceptance contract.
5. `backend/tests/unit/test_strategy_ir_schema.py` — Schema validation, round-trip serialization, option legs, invalid node rejection, migration, and JSON Schema export tests.

## Acceptance scenarios

### B1 — Round-trip serialization and deserialization
- Valid StrategyIR instances serialize to JSON and deserialize with 100% equivalence.

### B2 — Signal node recursive hierarchy validation
- Complex nested boolean and stateful signal trees (`PriceLevelBreak` with `after`, `Sequence`, `Persist`) validate correctly.

### B3 — Option leg strike selectors
- Validates `atm`, `delta`, `premium`, and `absolute` strike selectors with positive lot sizing.

### B4 — Schema validation and invalid node rejection
- Rejects missing required fields (`horizon`, `strategy_type`), negative lookback/periods, invalid enums, and malformed operands.

### B5 — Version migration
- `migrate_strategy_ir()` converts legacy schemas to target version.

### B6 — JSON Schema export
- Generates valid JSON Schema with full definitions suitable for AI model prompting and UI form generation.
