# F10.5 Acceptance Contract: Point-in-Time Sectoral Momentum Rotation Strategy

## Feature Definition
- **Feature ID**: F10.5
- **Name**: Point-in-time sectoral momentum rotation research strategy.
- **Dependencies**: F0.8, F2.5, F2.6, F2.7, F3.4, F3.9, F10.2
- **Proof Requirement**: G2, survivorship-bias checks, and enforced walk-forward evidence.

## Invariants & Acceptance Criteria

1. **Point-in-Time (PIT) Universe Membership & G2 Compliance**:
   - At each periodic rebalance date $t$, the strategy resolves sector and index constituents strictly as known on date $t$.
   - Delisted or demoted constituents are included during their active tenures; newly listed constituents are excluded prior to their addition dates.
   - Zero look-ahead bias: price and indicator inputs strictly respect bar timestamps $\le t$.

2. **Survivorship-Bias Verification**:
   - Implements explicit audit comparing backtest results under true point-in-time universe versus a naive static universe consisting only of current surviving members.
   - Quantifies the survivorship bias delta (e.g., return inflation in naive static universe caused by omitting historically distressed/delisted names).

3. **Multi-Horizon Sector Momentum Scoring**:
   - Calculates relative momentum score across candidate sectors (e.g. Bank, IT, FMCG, Auto, Pharma, Energy, Metal) using customizable lookback windows (e.g. 1M, 3M, 6M, 12M or blended momentum).
   - Incorporates absolute momentum filter (trend check): if a sector's return is negative or below cash benchmark, capital rotates to a defensive cash/gold proxy (e.g., GOLDBEES / liquid cash).
   - Dynamic allocation: selects top $K$ sectors, weighting by equal allocation or momentum rank.

4. **Enforced Walk-Forward Optimization & Validation**:
   - Evaluates the strategy across rolling or expanding train/test partitions using walk-forward analysis.
   - Reports:
     - In-Sample (IS) vs Out-of-Sample (OOS) CAGR, Sharpe ratio, and Max Drawdown.
     - Walk-Forward Efficiency (WFE) ratio: $\text{CAGR}_{\text{OOS}} / \text{CAGR}_{\text{IS}}$.
     - Robustness score and parameter stability across lookback configurations.

5. **REST API Interface**:
   - `POST /api/v1/investing/strategy/sectoral-rotation/backtest`: Execute point-in-time sectoral momentum backtest.
   - `POST /api/v1/investing/strategy/sectoral-rotation/walk-forward`: Execute walk-forward analysis with enforced OOS validation.
   - `POST /api/v1/investing/strategy/sectoral-rotation/survivorship-audit`: Run survivorship-bias audit comparing PIT vs static universe.

6. **Quality & Boundary Gates**:
   - `mypy backend --strict`, `ruff check .`, `pytest`, frontend checks, and manifest validation.
   - Zero modifications to protected paths (`backend/app/engine/risk.py`, `backend/app/engine/broker.py`, `backend/app/dhan/orders.py`, `backend/tests/parity/`).
