# F1.5 Acceptance Contract — Trading Sessions, Holidays, and Calendar Versions

## Feature

Per-segment Indian market trading sessions, versioned holiday calendar registry, deterministic IST/UTC timezone normalization, special session handling (Muhurat trading), and session boundary bar validation.

## Scope decisions recorded before implementation

- **Deterministic Timezone Normalization**:
  - Internal terminal timestamps and warehouse partitions are strictly UTC.
  - IST conversion (`Asia/Kolkata` / `+05:30`) is deterministic, bidirectional, and daylight-saving invariant.
- **Per-Segment Session Specifications**:
  - `NSE_EQ`, `BSE_EQ`, `NSE_FNO`, `BSE_FNO`, `IDX_I`: 09:15 to 15:30 IST.
  - `MCX_COMM`: 09:00 to 23:30 IST (summer) / 23:55 (winter).
  - `NSE_CURR`, `BSE_CURR`: 09:00 to 17:00 IST.
  - Special Sessions: Diwali Muhurat evening session (e.g., 18:15 to 19:15 IST) and Saturday disaster recovery switch sessions.
- **Published Versioned Holiday Calendars**:
  - Calendar registry loaded from `config/calendars/nse_calendar.yaml` with explicit `calendar_version` (e.g., `cal-2024-2027-v1`).
  - Standard national holidays (Republic Day, Independence Day, Gandhi Jayanti, Diwali, Holi, Good Friday, Christmas, etc.).
- **Session Boundary Validation**:
  - `TradingCalendar.is_session_time` and `validate_bar_session` verify that bars strictly fall within approved regular or special trading session windows.

## Required deliverables

1. `config/calendars/nse_calendar.yaml` — Published versioned holiday and special session calendar.
2. `backend/app/marketdata/calendar.py` — `TradingCalendar`, `SessionBounds`, `SpecialSession`, timezone helpers, and session validation.
3. `backend/app/marketdata/__init__.py` — Market data exports.
4. `docs/qa/acceptance/F1.5.md` — Acceptance contract.
5. `backend/tests/unit/test_trading_calendar.py` — Unit tests for trading days, holiday exclusion, session boundaries, special Muhurat sessions, timezone conversions, and session boundary validation.

## Acceptance scenarios

### B1 — Deterministic IST/UTC timezone conversions
- Verifies bidirectional conversions between UTC and IST timestamps with zero DST drift.

### B2 — Per-segment session bounds and trading day checks
- Normal weekdays return true for `is_trading_day`.
- Weekends (Saturday/Sunday) and listed holidays return false (unless a special session is explicitly scheduled).
- Validates regular trading session times (09:15 - 15:30 for EQ/FNO, 09:00 - 17:00 for CURR, 09:00 - 23:30 for COMM).

### B3 — Special Muhurat and DR session handling
- Diwali evening session is recognized as active during special session hours despite being a holiday.
- DR Saturday session is recognized with custom session bounds.

### B4 — Bar session boundary validation
- Validates that bars during session hours pass `validate_bar_session` and out-of-session bars (e.g. 02:00 IST or 16:30 IST for equity) fail validation.
