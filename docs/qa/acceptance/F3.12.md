# F3.12 Acceptance Contract — Shared Daily P&L and Time-Weighted Return (TWR) Model

## Feature

Universal daily accounting and Time-Weighted Return (TWR) engine shared across backtest, paper trading, and live execution modes, with realized P&L, Mark-to-Market (MTM) changes, transaction costs, external cashflows (deposits/withdrawals), and strict accounting identity verification.

## Scope decisions recorded before implementation

- **Accounting Identity Invariant**:
  - For every accounting day $t$:
    $$E_{end, t} = E_{start, t} + C_t + P_{real, t} + \Delta U_t - K_t$$
    where $E$ is equity, $C$ is external cashflow, $P_{real}$ is realized P&L, $\Delta U$ is unrealized MTM delta, and $K$ is total fees/taxes.
- **Time-Weighted Return (TWR)**:
  - Daily return is isolated from external cashflows:
    $$r_t = \frac{P_{net, t}}{E_{start, t} + C_t}$$
  - Cumulative TWR chains sub-periods geometrically:
    $$\text{TWR}_{1\dots T} = \prod_{t=1}^T (1 + r_t) - 1$$
- **Pure-Cashflow Invariant**:
  - External capital injection or withdrawal with zero trading P&L ($P_{net} = 0$) results in exactly $r_t = 0.0\%$ daily return and preserves cumulative TWR.
- **Multi-Period Compounding Property**:
  - Compounded returns across partitioned sub-periods match unified period return:
    $$(1 + \text{TWR}_{1\dots T}) = (1 + \text{TWR}_{1\dots k}) \cdot (1 + \text{TWR}_{k+1\dots T})$$
- **Breakdowns & Aggregations**:
  - Monthly, yearly, and rolling returns aggregated from daily accounting ledger.

## Acceptance scenarios

### B1 — Fundamental accounting identity validation
- Verifies daily ending equity matches $E_{start} + C + P_{real} + \Delta U - K$ across positive, negative, and mixed P&L scenarios.

### B2 — Pure cashflow 0% return invariance
- Injects massive cash deposit ($+₹500,000$) and withdrawal ($-₹200,000$) on non-trading days; verifies daily rate of return $r_t = 0.00\%$ and cumulative TWR is unchanged.

### B3 — Time-Weighted Return (TWR) compounding and cashflow immunity
- Verifies TWR correctly calculates true investment manager skill without distortion from client deposit timing.
- Verifies exact match with reference spreadsheet calculations.
