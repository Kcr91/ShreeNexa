# F2.8 Acceptance Contract — Point-in-Time Screener Runner

## Feature

Point-in-time screener execution runner evaluating arbitrary StrategyIR signal AST filters across historical index universes and multi-instrument datasets as-of any historical timestamp, with strict survivorship-bias tracking and zero future lookahead (G2).

## Scope decisions recorded before implementation

- **Point-in-Time Universe Resolution**:
  - Resolves active index constituents as-of target date $T$ via `IndexConstituentDB` / historical membership records.
  - Emits explicit `SurvivorshipBiasWarning` when membership history is unverified or falls outside recorded index constituent windows.
- **Unified StrategyIR Signal AST Filter**:
  - Uses the same `SignalNode` grammar (`And`, `Or`, `Not`, `IndicatorCompare`, `CrossOver`, `CrossUnder`, `PriceLevelBreak`, `Sequence`, `TimeWindow`, `PctChange`, `Persist`) as StrategyIR.
  - Computes declared technical indicator primitives and custom formulas over historical warmup windows.
- **Point-in-Time Screener Engine (`PointInTimeScreenerRunner`)**:
  - `run(screener: ScreenerDefinition, bar_store: Any) -> ScreenerResult`:
    - Evaluates data strictly up to $T$ (no future data leakage).
    - Returns structured `ScreenerMatch` items with matching indicator values, rank score, and provenance metadata.
- **Verification Proofs**:
  - **Three Hand-Verified Names**: Hand-calculated indicator and membership fixtures for 3 distinct stocks verifying exact match/rejection logic.
  - **G2 Anti-Lookahead Property**: Adding bars with timestamp $> T$ produces identical screener results at $T$.
  - **Survivorship-Bias Warning**: Warns when evaluating across static universes or unverified historical constituent snapshots.

## Acceptance scenarios

### B1 — Three hand-verified constituent screening
- Stock A (satisfies breakout and RSI filter) matches.
- Stock B (fails RSI filter) rejected.
- Stock C (delisted prior to date $T$) excluded by point-in-time universe resolution.

### B2 — G2 Anti-lookahead invariance
- Evaluates universe as-of $T$; adding future data for $t > T$ produces byte-identical screener matches.

### B3 — Survivorship-bias detection
- Emits explicit warning when historical constituent membership data is missing or incomplete.
