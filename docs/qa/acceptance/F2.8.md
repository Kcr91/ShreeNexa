# F2.8 Acceptance Contract — Indicator Mathematical Property Test Suite

## Feature

Property-based testing suite validating technical indicator mathematical invariants (identity laws, constant series invariance, scale homogeneity, translation invariance, bounds, envelope monotonicity) across both vectorized and incremental engines using Hypothesis.

## Scope decisions recorded before implementation

- **Mathematical Invariant Categories**:
  - **Identity Law ($N=1$)**: $SMA(X, 1) \equiv X$, $EMA(X, 1) \equiv X$.
  - **Constant Series**: Flat price series $C$ yields $SMA(C) = C$, $EMA(C) = C$, $RollingStd(C) = 0$, $ATR(C) = 0$, $Bollinger(C) = (C, C, C)$.
  - **Scale Homogeneity ($\alpha > 0$)**: $SMA(\alpha X) = \alpha SMA(X)$, $EMA(\alpha X) = \alpha EMA(X)$, $ATR(\alpha X) = \alpha ATR(X)$, $RollingStd(\alpha X) = \alpha RollingStd(X)$, $Bollinger(\alpha X) = \alpha Bollinger(X)$.
  - **Translation Invariance ($\beta \in \mathbb{R}$)**: $SMA(X + \beta) = SMA(X) + \beta$, $EMA(X + \beta) = EMA(X) + \beta$, $ATR(X + \beta) = ATR(X)$, $RollingStd(X + \beta) = RollingStd(X)$, $RSI(X + \beta) = RSI(X)$.
  - **Boundedness**: $0 \le RSI(X) \le 100$, $0 \le Stochastic(X) \le 100$.
  - **Envelope Ordering**: $Bollinger.lower \le Bollinger.middle \le Bollinger.upper$ at all non-null bars.
- **Dual-Engine Verification**:
  - Validates both batch vectorized (`VectorIndicator`) and streaming (`IncrementalIndicator`) execution pipelines.

## Required deliverables

1. `backend/tests/unit/test_indicator_properties.py` — Hypothesis property tests verifying mathematical invariants across random price trajectories.
2. `docs/qa/acceptance/F2.8.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Identity law & constant series invariance
- Property tests verify $N=1$ identity and flat series invariance across all relevant indicators.

### B2 — Scaling and translation invariance
- Verifies scaling by $\alpha > 0$ and translation by $\beta$ across prices.

### B3 — Bounds and envelope monotonicity
- Confirms RSI/Stochastic boundedness and Bollinger envelope ordering across diverse price paths.
