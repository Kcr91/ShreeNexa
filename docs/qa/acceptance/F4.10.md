# F4.10 Acceptance Contract — Frontend WebSocket Client with Auto-Reconnect, Multiplexing, and Live Tick Streamer

## Feature

Enterprise frontend WebSocket communication client featuring auto-reconnect with exponential backoff, channel multiplexing (quotes, depth, orders, positions, pnl), topic subscription management, latency telemetry, and a live feed status widget.

## Scope decisions recorded before implementation

- **Channel Multiplexing**:
  - Distinct channel subscriptions: `quotes`, `depth`, `orders`, `positions`, `pnl`.
  - Granular symbol-level listeners for targeted tick distribution.
- **Resilience and Auto-Reconnect**:
  - State machine: `CONNECTING`, `CONNECTED`, `DISCONNECTED`, `RECONNECTING`, `ERROR`.
  - Automatic reconnection retry with configurable maximum attempts and exponential backoff.
  - Heartbeat ping/pong keepalive management.
- **Live Feed Telemetry & UI Widget**:
  - `LiveFeedStatusWidget` displaying connection state badge, live latency (ms), active subscription count, and real-time tick streaming ticker.
  - Registered in `widgetRegistry` under category `analytics`.

## Required deliverables

1. `frontend/src/websocket/types.ts` — Type definitions for WebSocket protocol, channels, ticks, order/position updates.
2. `frontend/src/websocket/client.ts` — `NexaWebSocketClient` with multiplexing, auto-reconnect, and mock simulator.
3. `frontend/src/websocket/WebSocketContext.tsx` — React context provider and consumer hooks.
4. `frontend/src/widgets/builtin/LiveFeedStatusWidget.tsx` — Live connection monitor and tick stream widget.
5. `frontend/src/widgets/builtin/index.ts` — Registration of `liveFeedStatusDefinition`.
6. `frontend/src/websocket/client.test.ts` and `LiveFeedStatusWidget.test.tsx` — Unit tests.
7. `docs/qa/acceptance/F4.10.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Channel multiplexing and message routing
- Subscribing to `quotes` and `orders` dispatches incoming ticks and order updates to appropriate topic callbacks.

### B2 — Auto-reconnect on connection drop
- Simulating a disconnect triggers state transition to `RECONNECTING` and attempts reconnection with backoff.

### B3 — Live Feed Status Widget rendering
- Renders connection badge, latency monitor, active channels, and live symbol stream.
