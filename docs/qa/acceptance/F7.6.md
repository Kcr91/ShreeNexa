# F7.6 Acceptance Contract — Sector Watchlists and Index Drill-In

## Feature

Sector watchlists and index constituent drill-in driven by effective membership/provenance.

## Scope decisions recorded before implementation

- **Storage & Authority (ADR-0003)**:
  - `worker` owns ingestion of effective-dated index memberships and weights (F0.8).
  - `api` exposes index constituent and sector drill-in endpoints (`/api/v1/indices`).
- **Point-in-Time Membership Queries**:
  - Constituents can be queried as of "Latest / Live" or as of an explicit historical date (`as_of=YYYY-MM-DD`).
  - Strict point-in-time filtering: an instrument is returned only if `valid_from <= as_of <= (valid_to or infinity)`.
- **Transparent Provenance & Visible Stale Fallback (Core Invariant)**:
  - Every constituent record carries its provenance metadata (`source`, `source_date`, `valid_from`, `valid_to`).
  - If constituent data is sourced from `FALLBACK_SEED` or is older than the requested date, the UI and API explicitly flag it with a visible fallback/stale badge:
    `⚠️ Fallback Data (Source: FALLBACK_SEED)`. Stale fallback is never presented as verified official data.
- **Constituent Drill-In & Sector Watchlists**:
  - Drill-in view per index/sector displaying:
    - Symbol, Sector, Weight (%), LTP, Change %, Provenance, Valid Interval.
  - One-click action to save or export the constituents as an active user watchlist (F7.5).
- **Sector Classification**:
  - Support major Indian market sector indices: "NIFTY BANK", "NIFTY IT", "NIFTY AUTO", "NIFTY PHARMA", "NIFTY FMCG", "NIFTY METAL", "NIFTY ENERGY", "NIFTY REALTY", and benchmark indices "NIFTY 50", "NIFTY NEXT 50".

## Required deliverables

1. `backend/app/api/universe.py` — Extended with `/api/v1/indices/{index_name}/provenance` and sector breakdown summary.

3. `frontend/src/sector/api.ts` — Frontend client for querying effective-dated index constituents.
4. `frontend/src/widgets/builtin/SectorDrillInWidget.tsx` — Rich widget providing index/sector selector, date picker, visible stale fallback badge, constituent table, and "Save to Watchlist" integration.

6. `backend/tests/unit/test_sector_drill_in_api.py` — Python unit tests verifying effective-date queries and provenance metadata.
7. `frontend/src/sector/sector.test.ts` and `frontend/src/widgets/builtin/SectorDrillInWidget.test.tsx` — Frontend tests verifying historical date selection, fallback visibility, and watchlist export.
8. `docs/qa/acceptance/F7.6.md` — Acceptance contract.
