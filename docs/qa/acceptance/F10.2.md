# F10.2 Acceptance Contract — XIRR, Sector/Asset Allocation & Benchmark-Aware Performance

## Feature

Provides quantitative portfolio performance metrics for long-term investing portfolios:
1. Exact Excel-parity XIRR (Extended Internal Rate of Return) computation over irregular cash flow dates.
2. Robust root-finding using hybrid Newton-Raphson with bisection fallback, with explicit failure handling for non-convergent, degenerate, or multiple-root cashflows.
3. Portfolio sector, asset class, and market-cap breakdown derived from active holdings in `HoldingsLedger`.
4. Benchmark-aware performance comparison against index benchmarks (e.g. Nifty 50, Nifty 500) computing excess return (alpha) and benchmark CAGR.

## Scope decisions recorded before implementation

- **XIRR Solver & Excel Parity**:
  - Implements the discounted cash flow equation: $\sum_{i=0}^{n-1} C_i (1 + r)^{-\frac{d_i - d_0}{365}} = 0$.
  - Cash flows require at least one negative amount (outflow/investment) and at least one positive amount (inflow/valuation).
  - Matches Excel `XIRR(values, dates)` within $10^{-5}$ tolerance on standard benchmarks (e.g., periodic SIPs with terminal valuation).
  - Explicit error handling:
    - Degenerate inputs (all positive or all negative) raise `XIRRInvalidCashflowsError`.
    - Divergent or non-convergent series raise `XIRRConvergenceError`.
    - Multiple-root or extreme negative discount rate cases default to bounded search $[-0.999, 100.0]$.
- **Sector & Asset Class Allocation**:
  - Computes value and percentage weights for each sector (e.g. Energy, Technology, Banking & Finance, Automobiles, FMCG, Healthcare).
  - Computes asset class allocation (Equity, ETFs, Cash, Mutual Funds).
  - Flags concentration risk thresholds (e.g., sector weight $> 30\%$, single holding $> 20\%$).
- **Benchmark Performance**:
  - Compares portfolio XIRR against buy-and-hold benchmark XIRR across the identical cashflow investment schedule.
  - Computes benchmark alpha: $\alpha = \text{Portfolio XIRR} - \text{Benchmark XIRR}$.
- **REST Endpoints**:
  - `POST /api/v1/investing/xirr`: Computes XIRR from an explicit series of dated cash flows or current portfolio cashflows.
  - `GET /api/v1/investing/allocation`: Computes sector, asset class, and market cap weights.
  - `POST /api/v1/investing/benchmark-comparison`: Compares portfolio performance against benchmark returns.
