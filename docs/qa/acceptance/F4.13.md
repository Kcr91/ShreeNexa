# F4.13 Acceptance Contract — Strategy Marketplace / Library Browser Widget

## Feature

Quant Strategy Marketplace and Library Browser widget featuring curated institutional strategies across Indian Equities, Options, and Futures, with category filtering, author badges, backtest tear sheet modal previews, and one-click cloning to the Strategy Builder workspace.

## Scope decisions recorded before implementation

- **Curated Indian Market Strategy Catalog**:
  - Library covering Momentum, Options Income, Trend Following, 0DTE Gamma Scalping, and Volatility Mean Reversion.
  - Complete with StrategyIR schema definitions matching F2.5/F4.12, verified author cards, and audited backtest performance scorecards (CAGR, Sharpe, Max DD, Win Rate).
- **Search & Multi-Facet Categorization**:
  - Filter by asset class (`EQUITY`, `OPTIONS`, `FUTURES`), category tags, and search query keywords.
- **Tear Sheet Modal Preview**:
  - Detailed modal inspector displaying CAGR, Sharpe, Win Rate, Profit Factor, Max Drawdown, and monthly performance scorecard.
- **One-Click Clone to Workspace**:
  - Clone action serializes and loads the strategy's `StrategyIR` into active workspace storage / clipboard.
- **Widget Registry Integration**:
  - Registered in `widgetRegistry` under category `analytics`.

## Required deliverables

1. `frontend/src/marketplace/types.ts` — Type definitions for marketplace strategies, author cards, performance scorecards, and settings.
2. `frontend/src/marketplace/catalog.ts` — Curated strategy library with authentic Indian market models and valid `StrategyIR`.
3. `frontend/src/marketplace/TearSheetModal.tsx` — Modal displaying detailed performance metrics and strategy rules.
4. `frontend/src/widgets/builtin/StrategyMarketplaceWidget.tsx` — Marketplace browser widget with search, filtering, tear sheet preview, and one-click clone.
5. `frontend/src/widgets/builtin/index.ts` — Registration of `strategyMarketplaceDefinition`.
6. `frontend/src/marketplace/catalog.test.ts` and `StrategyMarketplaceWidget.test.tsx` — Unit tests.
7. `docs/qa/acceptance/F4.13.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Strategy browsing and category filtering
- Renders curated strategy cards and filters dynamically by category tags and search keywords.

### B2 — Tear sheet performance modal preview
- Clicking "Preview Tear Sheet" opens modal displaying audited metrics, drawdown, and strategy IR rules.

### B3 — One-click clone action
- Clicking "Clone to Workspace" creates a cloned StrategyIR instance with notification feedback.
