# F1.4 Acceptance Contract — Expired-Option 30-Day Backfill and ATM Limits

## Feature

Expired-option 1-minute historical backfill chunked into 30-day windows, strict ATM coverage limits (ATM±10 for index options, ATM±3 for stock options), explicit `strike_unavailable` reporting with zero silent substitution, raw ingest provenance, and atomic warehouse publication.

## Scope decisions recorded before implementation

- **30-Day Window Slicing**:
  - Date ranges are sliced into continuous, non-overlapping `<= 30`-day windows conforming to Dhan's rolling option chart API constraints.
- **Strict ATM Strike Limits (No Silent Substitution)**:
  - Index options: Allowed range is ATM ± 10 strike increments.
  - Stock options: Allowed range is ATM ± 3 strike increments.
  - If a strike outside the allowed range is requested, `StrikeUnavailableError` is raised with code `"strike_unavailable"`.
  - The engine and worker must never silently substitute a nearby or adjacent strike.
- **Typed Option Schema**:
  - `OptionBarRecord` and `OPTION_BAR_SCHEMA_PYARROW` record `timestamp`, `exchange_segment`, `security_id`, `symbol`, `underlying_symbol`, `expiry_date`, `strike_price`, `option_type`, `open`, `high`, `low`, `close`, `volume`, `open_interest`, `implied_volatility`, and `spot_price`.
- **Immutable Raw Ingest Provenance**:
  - Raw JSON responses are saved under `data/raw/dhan/charts_options/<YYYY>/<MM>/<ingest_id>/payload.json` with parameter sanitization.
- **Warehouse Publication**:
  - Option partitions are staged under `options/segment=<segment>/year=<YYYY>/month=<MM>/<underlying>_<expiry>_<strike>_<type>.parquet` and published atomically via `WarehousePublisher` (F1.1).

## Acceptance scenarios

### B1 — 30-day window generator
- Splits multi-month date ranges into `<= 30`-day non-overlapping windows.

### B2 — ATM strike coverage enforcement
- Requesting strike within ATM±10 on NIFTY succeeds.
- Requesting strike beyond ATM±10 on NIFTY raises `StrikeUnavailableError("strike_unavailable")`.
- Requesting strike within ATM±3 on stock options succeeds.
- Requesting strike beyond ATM±3 on stock options raises `StrikeUnavailableError("strike_unavailable")`.
- Verifies zero silent fallback or nearby strike substitution occurs.

### B3 — Rolling option candle parsing
- Parses Dhan `/charts/rollingoption` response into typed `OptionBarRecord` objects including IV and spot price.

### B4 — Warehouse publication and DuckDB queries
- Promotes staged option Parquet partitions to the analytical warehouse and queries them accurately via DuckDB.
