# F2.3 Acceptance Contract — Safe Formula Parser, AST Validator, and Compiler

## Feature

Safe domain-specific formula parser, AST sandbox validator, compiler, and restricted evaluator for user-defined technical indicator and signal expressions with complete security sandbox enforcement and lookahead prevention.

## Scope decisions recorded before implementation

- **Strict AST White-List Sandboxing**:
  - Permitted AST Nodes:
    - `ast.Expression`, `ast.BinOp` (`+`, `-`, `*`, `/`, `**`, `%`), `ast.UnaryOp` (`+`, `-`, `not`, `~`), `ast.BoolOp` (`and`, `or`), `ast.Compare` (`<`, `<=`, `>`, `>=`, `==`, `!=`), `ast.IfExp` (ternary conditional `x if c else y`), `ast.Call` (allowlisted functions only), `ast.Name` (allowlisted identifiers: `open`, `high`, `low`, `close`, `volume`, `oi`), `ast.Constant` (numeric / boolean literals).
  - Explicit Rejection with `FormulaSecurityError`:
    - `ast.Attribute` (all attribute access `x.y` blocked to eliminate `__globals__`, `__subclasses__`, etc.).
    - `ast.Import`, `ast.ImportFrom` (`import ...` blocked).
    - `ast.Lambda`, `ast.ListComp`, `ast.DictComp`, `ast.SetComp`, `ast.GeneratorExp`.
    - `ast.AsyncFunctionDef`, `ast.FunctionDef`, `ast.ClassDef`, `ast.Delete`, `ast.Global`, `ast.Nonlocal`.
    - Any identifier starting/ending with double underscores (`__...__`).
    - Negative subscript indexing (`close[-1]` lookahead bias).
- **Allowlisted Built-in Functions**:
  - Indicator registry primitives: `sma`, `ema`, `macd`, `supertrend`, `rsi`, `stoch`, `roc`, `atr`, `bollinger_bands`, `obv`, `vwap`, `zscore`, `rolling_std`.
  - Signal / Math helpers:
    - `crossover(a, b)`: True when $a_t > b_t$ and $a_{t-1} \le b_{t-1}$.
    - `crossunder(a, b)`: True when $a_t < b_t$ and $a_{t-1} \ge b_{t-1}$.
    - `cross(a, b)`: True on any crossover or crossunder.
    - `shift(series, bars)`: Backward shift ($t - \text{bars}$ where $\text{bars} \ge 0$).
    - `highest(series, period)`, `lowest(series, period)`.
    - `abs(x)`, `min(a, b)`, `max(a, b)`, `if_else(condition, true_val, false_val)`.
- **Restricted Evaluator**:
  - `FormulaCompiler.compile(formula: str) -> CompiledFormula`.
  - `CompiledFormula.evaluate(data: pa.Table | dict[str, Any]) -> list[float | bool | None]`.
  - Propagates `None` values safely across arithmetic and boolean operations.
- **Security Fuzz Suite**:
  - Adversarial payloads (arbitrary code execution, attribute extraction, imports, lookahead shifts, formatting exploits) must fail deterministically at parse/validation time.

## Acceptance scenarios

### B1 — Sandboxed AST validation rejecting malicious payloads
- Blocks `__import__`, `eval`, `exec`, attribute access, lambdas, list comprehensions, and system calls at parse time.

### B2 — Lookahead prevention
- Rejects negative shift offsets or forward indexing.

### B3 — Mathematical expression compilation and evaluation
- Correctly parses and evaluates complex compound formulas (e.g. `crossover(ema(close, 9), ema(close, 21)) and rsi(close, 14) > 50`).

### B4 — Element-wise operations and None propagation
- Correctly evaluates arithmetic and logic across aligned series with `None` handling.
