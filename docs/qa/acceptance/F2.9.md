# F2.9 Acceptance Contract — Screener Persistence, Scheduling, Ranking, Export, and Routing

## Feature

Screener persistence layer, offline scheduled execution engine, snapshot audit trails, CSV/JSON export formats, and routing of screener matches directly to user watchlists and StrategyIR static universes.

## Scope decisions recorded before implementation

- **Screener Storage and Audit History**:
  - `ScreenerStore`: Persists screener definitions with metadata, ranking preferences, and cron schedule expressions.
  - `ScreenerRunHistory`: Captures immutable execution snapshots containing matched symbols, indicator values, rank order, execution timestamps, and audit warnings.
- **Offline Scheduler**:
  - `ScreenerScheduler`: Executes scheduled screener evaluation jobs offline against point-in-time warehouse data.
- **Export & Routing**:
  - `export_screener_csv` / `export_screener_json`: Formats screener results into downloadable tables.
  - `route_to_watchlist`: Populates a designated watchlist with matched security IDs.
  - `route_to_static_universe`: Transforms screener matches into a valid `StrategyIR.StaticUniverse` for backtesting and automated strategy generation.
- **FastAPI Screener API**:
  - CRUD endpoints (`/api/v1/screeners`, `/api/v1/screeners/{id}`)
  - Execution endpoint (`POST /api/v1/screeners/{id}/run`)
  - History & export endpoints (`GET /api/v1/screeners/{id}/runs`, `POST /api/v1/screeners/{id}/runs/{run_id}/export`)
  - Routing endpoints (`POST /api/v1/screeners/{id}/runs/{run_id}/route-watchlist`, `POST /api/v1/screeners/{id}/runs/{run_id}/route-universe`)

## Acceptance scenarios

### B1 — Screener CRUD and execution persistence
- Creates screener definition, executes point-in-time run, and verifies that the run snapshot is saved with reproducible matched results and audit history.

### B2 — Offline scheduled run execution
- Triggers scheduled execution job and verifies immutable snapshot is saved to store.

### B3 — Export to CSV and JSON
- Generates valid RFC-4180 CSV and JSON strings with headers and indicator values.

### B4 — Routing to watchlist and StrategyIR universe
- Successfully routes screener matches to a watchlist and generates a valid `StaticUniverse` for StrategyIR.
