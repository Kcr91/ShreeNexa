# F2.9 Acceptance Contract — Indicator Catalog and Formula Validation API

## Feature

FastAPI endpoints for technical indicator discovery, parameter metadata catalogs, and real-time safe formula syntax and security validation.

## Scope decisions recorded before implementation

- **Endpoints**:
  - `GET /api/v1/indicators` (and `/api/indicators`): Lists all registered indicators (`name`, `family`, `description`, `output_keys`, `default_params`).
  - `GET /api/v1/indicators/{name}` (and `/api/indicators/{name}`): Retrieves single indicator metadata or returns 404.
  - `POST /api/v1/indicators/validate-formula` (and `/api/indicators/validate-formula`): Validates formula syntax, AST security sandboxing, and lookahead rules; returns `{valid, identifiers, error}`.
- **Security Validation**:
  - Validates formulas using `FormulaCompiler.compile()` and `FormulaASTValidator`.
  - Rejects malicious payloads (dunder, imports, lambdas, attribute access) and negative indexing without code execution.

## Acceptance scenarios

### B1 — Catalog discovery endpoint
- `GET /api/v1/indicators` returns all 12 primitives with valid families and parameter schemas.

### B2 — Individual indicator metadata retrieval
- `GET /api/v1/indicators/sma` returns 200 with default parameters; `GET /api/v1/indicators/unknown` returns 404.

### B3 — Safe formula validation endpoint
- `POST /api/v1/indicators/validate-formula` accepts valid formula `sma(close, 5) > sma(close, 20)` with `valid: true`.
- Rejects adversarial syntax `__import__('os')` with `valid: false` and informative error message.
