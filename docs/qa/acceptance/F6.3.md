# F6.3 Acceptance Contract — Cross-Strategy Return and Signal Correlation Matrices

## Feature

Cross-strategy pairwise return and signal correlation matrices, configurable missing-period handling policies, and robust mathematical handling of constant and short time series.

## Scope decisions recorded before implementation

- **NumPy Reference Parity**:
  - Correlation calculations between active strategy return series match NumPy's `np.corrcoef` within $10^{-6}$ numerical tolerance.
  - The correlation matrix is strictly symmetric ($M_{ij} = M_{ji}$) with unity diagonal ($M_{ii} = 1.0$).
- **Missing-Period Policy**:
  - `MissingPeriodPolicy.DROP_COMMON`: Discards non-overlapping dates, computing correlation only on common active timestamps (pairwise inner join).
  - `MissingPeriodPolicy.FILL_ZERO`: Fills non-active strategy dates with 0.0 return (appropriate when a strategy is out of market / cash).
  - `MissingPeriodPolicy.FORWARD_FILL`: Carries previous signal/level forward.
- **Constant Series Behavior**:
  - In financial time series where a strategy is in cash (zero return across all bars) or produces constant signals, variance is 0.0.
  - Pure Pearson formula yields $0/0$. The engine explicitly returns `0.0` with an explanatory warning flag, preventing unhandled `ZeroDivisionError` or propagating `NaN` into portfolio optimizers.
- **Short Series Behavior**:
  - Minimum periods parameter (`min_periods >= 2`). Pairs with fewer common observations return `0.0` (or `None`/`NaN`) with an explicit short-series warning.
- **Signal Correlation**:
  - Computes correlation across discrete signal vectors (Long=+1, Flat=0, Short=-1) over aligned timestamps to evaluate strategy redundancy and diversification.

## Acceptance scenarios

### C1 — Reference fixture parity
- Compares calculated correlation matrix against `numpy.corrcoef` on multi-series dataset; verifies $|r_{calc} - r_{numpy}| \le 10^{-6}$.
- Verifies diagonal elements are 1.0 and $M_{ij} == M_{ji}$.

### C2 — Missing-period policy handling
- Verifies `DROP_COMMON` excludes non-overlapping dates.
- Verifies `FILL_ZERO` aligns to the union of dates and pads missing dates with 0.0.
- Verifies sample count matrix accurately records overlapping observation counts.

### C3 — Constant series and zero-variance behavior
- Tests a strategy with zero volatility (constant return 0.0); verifies the engine returns 0.0 correlation without throwing exceptions.

### C4 — Short series behavior
- Verifies pairs with fewer than `min_periods` observations are flagged with short-series warnings.
