# F11.4 Acceptance Contract: Gate Harness for G1-G6, Filtered Failure Summaries, and Bounded Retry Policy

## Feature Definition
- **Feature ID**: F11.4
- **Name**: Gate harness for G1-G6 plus filtered failure summaries and bounded retry policy.
- **Dependencies**: F11.3
- **Proof Requirement**: Deliberately broken parity/look-ahead/type/UI/protected-path fixtures are all blocked.

## Invariants & Acceptance Criteria

1. **G1-G6 Quality Gates Architecture**:
   - The harness evaluates six cross-cutting gates defined in `docs/qa/gates.md`:
     - **G1 (Parity Gate)**: Verifies bit-for-bit mathematical and signal equivalence between vectorized (`VectorStrategyCompiler`) and incremental (`IncrementalStrategyEngine`) evaluation modes.
     - **G2 (No-Look-Ahead Gate)**: Truncated-history evaluation audit ensuring decisions at bar $t \le T$ do not depend on bars $t > T$, and universe constituents adhere to point-in-time membership.
     - **G3 (Determinism Gate)**: Identical inputs, seeds, configurations, and versions yield byte-identical outcomes across repeat executions.
     - **G4 (Static Analysis & Compilation Gate)**: Verifies Ruff linting, strict Mypy typing, frontend TypeScript typecheck, Vitest unit tests, and Vite production bundle compilation.
     - **G5 (Coverage Gate)**: Enforces code coverage thresholds (90% analytics/IR/engine/backtest, 80% other backend, 70% UI).
     - **G6 (Protected-Paths Audit Gate)**: Inspects branch diff to ensure no unattended changes to protected modules (`engine/risk.py`, `engine/broker.py`, `dhan/orders.py`, `backend/tests/parity/`).

2. **Filtered Failure Summaries**:
   - Raw output from failed gate runs (e.g. hundreds of lines of pytest or mypy or tsc logs) is compressed into concise, structured, prioritized diagnostic summaries (`FilteredFailureSummary`):
     - `gate`: Gate identifier (G1–G6).
     - `category`: Classification of failure (e.g. `PARITY_MISMATCH`, `LOOK_AHEAD_LEAK`, `TYPE_CHECK_FAILURE`, `PROTECTED_PATH_VIOLATION`, `COVERAGE_DEFICIT`).
     - `culprit_files`: Specific offending file paths.
     - `culprit_lines`: Offending line numbers or test case identifiers.
     - `message`: Focused, actionable diagnostic message stripped of noisy tracebacks.

3. **Bounded Retry Policy**:
   - Defines bounded retry management (`RetryPolicy`):
     - `max_retries`: Maximum automated retry attempts (default 3).
     - `backoff_factor`: Exponential or stepped backoff cooldown between attempts.
     - `current_attempt`: Tracked attempt counter.
   - **Non-retryable Policy Violations**:
     - G6 (Protected Path Violation) is strictly **NON-RETRYABLE** and halts execution immediately with `HALTED_POLICY_VIOLATION`.
     - Malicious/deliberate look-ahead leaks that cannot be resolved automatically are halted immediately.
     - Once `current_attempt >= max_retries`, task status transitions permanently to `FAILED_GATE_HARNESS`.

4. **Proof Invariants (Deliberately Broken Fixtures Blocked)**:
   - Deliberately broken parity fixture -> G1 gate blocks with clear mismatch diagnosis.
   - Deliberately broken look-ahead fixture -> G2 gate blocks with future-bar leak diagnosis.
   - Deliberately broken type / syntax / UI fixture -> G4 gate blocks with filtered compiler diagnosis.
   - Deliberately broken coverage fixture -> G5 gate blocks with coverage deficit diagnosis.
   - Deliberately modified protected path -> G6 gate blocks immediately with security audit violation and zero retries allowed.

5. **REST API Interface**:
   - `POST /api/v1/feature-builder/gates/evaluate`: Evaluates G1-G6 gates on a candidate worktree or simulated candidate.
   - `GET /api/v1/feature-builder/gates/{task_id}`: Retrieves gate execution results, summaries, and retry status.
   - `POST /api/v1/feature-builder/gates/{task_id}/retry`: Executes bounded retry if permitted by policy.

6. **Repository Invariants**:
   - Zero changes to protected paths (`backend/app/engine/risk.py`, `backend/app/engine/broker.py`, `backend/app/dhan/orders.py`, `backend/tests/parity/`).
   - All tests pass; full typecheck and linter clean.
