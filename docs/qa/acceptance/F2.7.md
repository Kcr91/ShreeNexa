# F2.7 Acceptance Contract — Incremental StrategyIR Compiler and Evaluator with State Recovery

## Feature

Streaming incremental compiler and execution engine for `StrategyIR` specifications, maintaining real-time technical indicator states, recursive signal grammar evaluation, state checkpointing/restoration, and exact bit-for-bit parity against the vectorized strategy engine.

## Scope decisions recorded before implementation

- **Incremental Strategy Pipeline**:
  - `IncrementalStrategyCompiler`: Compiles `StrategyIR` into an `IncrementalStrategyEngine`.
  - Instantiates `IncrementalIndicator` instances for declared primitives and maintains streaming signal node evaluators.
- **Bar Update Protocol**:
  - `update(bar: BarRecord) -> StrategyEvaluationStep`:
    - Computes new indicator values in $O(1)$ time complexity per bar.
    - Evaluates all `entry` and `exit` signal trees against current and historical bar state.
    - Returns `entry_signals: dict[str, bool]`, `exit_signals: dict[str, bool]`, and `indicator_values: dict[str, Any]`.
- **Stateful Signal AST Node Handlers**:
  - `CrossOver` / `CrossUnder`: Maintains previous bar operand values.
  - `Sequence`: Sliding window deque tracking step triggers within `within` bar window.
  - `PriceLevelBreak`: Tracks daily session reference levels and `after` condition states.
  - `Persist`: Rolling counter of consecutive true evaluations.
  - `PctChange`: Rolling buffer of length `lookback + 1`.
  - `TimeWindow`: Evaluates current bar timestamp against configured mode.
- **State Checkpointing & Recovery**:
  - `get_state() -> dict[str, Any]`: Serializes complete state across indicators and signal nodes.
  - `restore_state(checkpoint: dict[str, Any]) -> None`: Restores engine state idempotently.
  - `reset() -> None`: Resets all internal buffers.
- **Vector / Incremental Parity Guarantee (Repository Parity Suite)**:
  - Validates that streaming a series of $N$ bars sequentially through `IncrementalStrategyEngine.update()` produces the exact same boolean entry and exit signals as `CompiledStrategy.evaluate()` on the same bar series.

## Acceptance scenarios

### B1 — Real-time streaming strategy evaluation
- Evaluates canonical ORB strategy bar-by-bar in $O(1)$ per bar.

### B2 — Vector / incremental strategy parity
- Asserts that entry and exit signals generated across $N$ bars match `CompiledStrategy.evaluate()` with 100% equivalence.

### B3 — State checkpointing and recovery
- Restores internal indicator buffers and signal node state mid-stream without signal drift.

### B4 — Reset lifecycle
- Clears all stateful buffers on reset.
