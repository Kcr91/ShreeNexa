# F2.7 Acceptance Contract — Composite Indicator Matrix Engine

## Feature

High-performance composite indicator matrix engine computing multi-instrument indicator matrices across broad stock/index universes with exact mathematical parity against sequential single-instrument runs.

## Scope decisions recorded before implementation

- **Universe-Wide Batch Execution**:
  - `UniverseIndicatorMatrixEngine` computes multi-node indicator dependency graphs across universes (e.g. 50+ symbols) over specified date ranges and timeframes.
  - Leverages DuckDB/Parquet `BarStore` (F1.1) or in-memory bar datasets.
- **Output Schema**:
  - Output format is a unified PyArrow Table containing `["symbol", "timestamp", "open", "high", "low", "close", "volume", ...<indicator_nodes>]` sorted by `["symbol", "timestamp"]` or `["timestamp", "symbol"]`.
- **Mathematical Matrix Parity Proof**:
  - Runs batch matrix computation across a 50-instrument universe and asserts exact cell-by-cell numerical parity ($< 10^{-5}$) against individual sequential `IndicatorExecutionPlan` runs.

## Required deliverables

1. `backend/app/indicators/matrix.py` — `UniverseIndicatorMatrixEngine`.
2. `backend/app/indicators/__init__.py` — Package exports.
3. `docs/qa/acceptance/F2.7.md` — Acceptance contract.
4. `backend/tests/unit/test_universe_matrix_engine.py` — Unit tests covering 50-instrument universe batch computation and parity against sequential single-instrument runs.

## Acceptance scenarios

### B1 — Universe-wide matrix computation across 50 instruments
- Computes compound indicator DAGs for 50 distinct instruments in a single batch.

### B2 — Exact cell-by-cell parity with sequential runs
- Validates that matrix values match single-instrument runs across all symbols, timestamps, and indicator columns.

### B3 — Empty universe and missing symbol handling
- Safely handles empty input sets and preserves existing symbols when some instruments have partial data.
