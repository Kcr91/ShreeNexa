# F3.9 Acceptance Contract — Overfitting and P-Hacking Controls

## Feature

Statistical multi-testing correction and backtest overfitting diagnostics implementing the Deflated Sharpe Ratio (DSR), Combinatorially Symmetric Cross-Validation (CSCV) Probability of Backtest Overfitting (PBO), and White's Reality Check (WRC).

## Scope decisions recorded before implementation

- **Deflated Sharpe Ratio (DSR - Bailey & López de Prado)**:
  - Adjusts the standard Sharpe Ratio for non-normal return distributions (skewness $\gamma_3$ and kurtosis $\gamma_4$), sample length $T$, number of tested strategy configurations $N$, and variance of strategy trials $V$.
  - Computes Probabilistic Sharpe Ratio ($PSR$) and expected maximum Sharpe ratio under the null hypothesis $SR_0$.
- **Probability of Backtest Overfitting (PBO - CSCV)**:
  - Partitions historical performance matrix into $S$ contiguous slices (e.g. $S=16$).
  - Evaluates all $\binom{S}{S/2}$ combinations of In-Sample training vs Out-of-Sample testing sets.
  - Computes the empirical probability $PBO = \Pr(\lambda_c > 0.5)$ that the In-Sample optimal strategy underperforms the median in Out-of-Sample testing.
- **White's Reality Check (WRC)**:
  - Evaluates the null hypothesis $H_0: \max_k \mathbb{E}[R_k] \le 0$ across multiple strategy parameter trials using stationary bootstrap resampling.
  - Computes empirical snooper-adjusted $p$-value.
- **Verification & Mathematical Exactness**:
  - Reconciles DSR, PSR, PBO, and WRC against exact analytical hand calculations.

## Acceptance scenarios

### B1 — Deflated Sharpe Ratio (DSR) and Multiple Testing Penalty
- Evaluates strategy with $\widehat{SR} = 1.5$ over $T=500$ daily returns tested across $N=100$ trials with variance $V=0.25$.
- Verifies reduction in confidence ($DSR < PSR$) due to the multiple testing selection penalty $SR_0 > 0$.
- Reconciles exact numerical values against closed-form formula.

### B2 — Probability of Backtest Overfitting (PBO) via CSCV
- Evaluates synthetic return matrix of 10 strategies over $S=6$ slices ($\binom{6}{3} = 20$ combinations).
- Reconciles empirical $PBO$ and logit distribution against hand calculation.

### B3 — White's Reality Check for Data Snooping
- Evaluates $N=20$ noise strategies (zero-mean normal returns); verifies White's Reality Check $p$-value correctly rejects false positives ($p > 0.05$).
- Evaluates genuine positive alpha strategy; verifies $p$-value is statistically significant ($p < 0.05$).
