# F2.6 Acceptance Contract — Multi-Timeframe Indicator Pipeline

## Feature

Timeframe-aware multi-resolution technical indicator pipeline calculating higher-timeframe indicators over resampled bars and projecting them onto base-resolution timestamps with strict lookahead-free point-in-time alignment.

## Scope decisions recorded before implementation

- **Session-Aware Resampling Integration**:
  - Leverages `BarResampler` (from F1.6) to generate higher-timeframe (HTF) bars (e.g., 5m, 15m, 60m, 1D) from base 1-minute historical/streaming bars.
- **Lookahead-Free Point-in-Time Alignment (Anti-Lookahead Rule)**:
  - Higher-timeframe indicators are only known after the higher-timeframe bar interval has fully closed.
  - For base timestamp $t$, the projected HTF value reflects the most recently completed HTF bar whose close time is $\le t$.
  - Within an active unclosed HTF bar, base bars receive the previous closed HTF bar's indicator value (or `None` during initial warm-up), preventing future bar leakage.
- **Multi-Resolution Execution**:
  - Supports single indicator primitives and compound indicator dependency graphs (`IndicatorDependencyGraph`).
  - Returns aligned series with column names matching the requested target resolutions (e.g. `sma5_15m`, `rsi_1d`).

## Acceptance scenarios

### B1 — Session-aware HTF resampling and indicator execution
- Accurately resamples 1m bars to 15m/60m/1D intervals and computes indicator series.

### B2 — Zero lookahead bias guarantee
- Confirms that base bars within an open HTF bar only see the previous completed bar's indicator value.

### B3 — Compound DAG multi-timeframe projection
- Projects multi-node compound graph outputs from HTF to base resolution.

### B4 — Warm-up period preservation
- Preserves `None` across base timestamps until the required number of HTF bars have closed.
