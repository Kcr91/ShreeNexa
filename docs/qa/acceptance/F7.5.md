# F7.5 Acceptance Contract — Multiple Manual and F&O Watchlists

## Feature

Multiple manual and F&O watchlists with configurable columns and stable ordering.

## Scope decisions recorded before implementation

- **Storage & Authority (ADR-0003)**:
  - `api` is the write owner for user watchlists.
  - Backend exposes REST API `/api/v1/watchlists` for managing multiple watchlists.
  - Frontend caches and persists watchlists in browser local storage (`shreenexa_watchlists_v1`) and synchronizes with the API.
- **Multiple Watchlists Support**:
  - Support creating, renaming, deleting, and switching across multiple manual and F&O watchlists.
  - Default built-in watchlists: "NIFTY 50", "BANK NIFTY F&O", "Breakout Watchlist".
- **Configurable Columns**:
  - Configurable column set: `Symbol`, `LTP`, `Change %`, `Change ₹`, `Volume`, `Open Interest (OI)`, `OI Change %`, `High / Low Range`, `Bid / Ask Spread`.
  - Column picker allowing users to show/hide columns per watchlist.
- **Stable Ordering**:
  - Explicit ordering sequence maintained for all items in a watchlist.
  - Reordering (Move Up / Move Down or position indexing) remains stable across browser reloads.
- **Resilience Against Instrument Master Refresh**:
  - Watchlist items store canonical identifiers (`segment`, `security_id`, `symbol`, `trading_symbol`).
  - When the instrument master is updated or refreshed, existing symbols and order are preserved and reconciled without losing user watchlists.
- **F&O Support**:
  - Supports derivative contract specifications (Futures and Options with `expiry`, `strike`, and `option_type`).
  - F&O columns include `OI` and `OI Change %` driven by live feed or cached data.

## Required deliverables

1. `backend/app/api/watchlists.py` — REST endpoints for creating, listing, updating, deleting, and reordering watchlists and items.
2. `backend/app/main.py` — Mount watchlists router at `/api/v1/watchlists`.
3. `frontend/src/watchlist/types.ts` — TypeScript interfaces for watchlists, items, and columns.
4. `frontend/src/watchlist/storage.ts` — Storage manager handling persistence, reconciliation, and default seeds.
5. `frontend/src/widgets/builtin/WatchlistWidget.tsx` — Rich interactive widget supporting multiple tabs, column picker, symbol addition/deletion, reordering, and live quote rendering.
6. `backend/tests/unit/test_watchlists_api.py` — Python unit tests for the watchlists REST endpoints.
7. `frontend/src/watchlist/watchlist.test.ts` and `frontend/src/widgets/builtin/WatchlistWidget.test.tsx` — Frontend tests verifying CRUD, column configuration, stable reordering, and instrument master refresh survival.
8. `docs/qa/acceptance/F7.5.md` — Acceptance contract.
