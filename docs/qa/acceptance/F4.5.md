# F4.5 Acceptance Contract — Order Ticket Widget with Multi-Leg Options, Margin Preview, and Execution Gates

## Feature

Comprehensive order ticket widget supporting stock equities, multi-leg options builder (Strangles, Straddles, Spreads, Condors), dynamic margin requirements preview (hedged SPAN/Exposure approximation), Indian regulatory cost breakdown, risk limit validation, and paper/live execution safety gates.

## Scope decisions recorded before implementation

- **Asset Class & Multi-Leg Builder Support**:
  - Equity stocks (CNC delivery, MIS intraday, Market/Limit).
  - Multi-leg options builder allowing dynamic addition/removal of option legs (Symbol, Expiry, Strike, CE/PE, BUY/SELL, Quantity, Premium).
- **Hedged Margin & Cost Preview**:
  - Computes gross and net margin requirement with multi-leg hedging offset benefits.
  - Indian regulatory cost model integration (STT, GST, Stamp duty, turnover charges).
- **Hard Safety & Risk Gates**:
  - Rejects orders exceeding available margin balance.
  - Rejects zero or invalid lot quantities.
  - **Live Execution Invariant**: Rejects live execution when live trading is unauthorized (gated behind Epic 12), ensuring no real broker orders can be placed.
- **Widget Registry Integration**:
  - Order ticket is registered in `widgetRegistry` under category `order`.

## Required deliverables

1. `frontend/src/order/types.ts` — Order models, leg definitions, and margin results.
2. `frontend/src/order/margin.ts` — SPAN/Exposure margin calculation and multi-leg hedging offsets.
3. `frontend/src/order/execution.ts` — Order validation and paper/live gate enforcement.
4. `frontend/src/widgets/builtin/OrderTicketWidget.tsx` — Order ticket component with equity and multi-leg option builder.
5. `frontend/src/widgets/builtin/index.ts` — Built-in registration of `orderTicketDefinition`.
6. `frontend/src/order/margin.test.ts`, `execution.test.ts`, and `OrderTicketWidget.test.tsx` — Unit tests.
7. `docs/qa/acceptance/F4.5.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Multi-leg option order margin preview
- Adding a short call and short put (Strangle) calculates combined margin requirement; adding long protective legs (Iron Condor) reduces required margin via hedging offset.

### B2 — Risk and margin limit validation
- Order exceeding available buying power is rejected with visible insufficient funds error.

### B3 — Live execution mode gating
- Attempting live order placement without active live session authorization is strictly blocked and returns safety rejection message.
