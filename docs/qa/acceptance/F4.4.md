# F4.4 Acceptance Contract — Lightweight Charts with Multi-Pane Indicators, Drawings, and Session Break Overlays

## Feature

High-performance candlestick and multi-asset charting using Lightweight Charts, featuring multi-pane indicators (overlay SMAs/EMAs/VWAP and sub-pane RSI/MACD), drawing annotations (trendlines, horizontal levels), and historical Indian market session break markers.

## Scope decisions recorded before implementation

- **Lightweight Charts Core**:
  - High-fps canvas-rendered candlestick series styled to the dark terminal palette (#00c076 up, #ff4d4f down).
- **Multi-Pane & Indicator Support**:
  - Main price pane hosts overlay series (SMA, EMA, VWAP).
  - Synchronized sub-panes render secondary oscillators (RSI 14, MACD 12/26/9, Volume histogram).
- **Indian Market Session Breaks**:
  - Session boundaries (09:15 IST opening bars or trading day changes) display distinct vertical session break markers matching historical session definitions from F1.5.
- **Interactive Drawings**:
  - Interactive drawing overlay supporting horizontal price lines and trendline anchors.
- **Widget Registry Integration**:
  - Chart widget is fully registered in `widgetRegistry` under category `chart` and discoverable via `WidgetPalette`.

## Required deliverables

1. `frontend/src/chart/types.ts` — Type definitions for bars, indicator configs, drawing objects, and session breaks.
2. `frontend/src/chart/indicators.ts` — Vector indicator computation algorithms for chart feeds (SMA, EMA, RSI, MACD, VWAP).
3. `frontend/src/chart/sessionBreaks.ts` — Indian market session boundary detector.
4. `frontend/src/chart/ChartContainer.tsx` — Multi-pane Lightweight Charts container with time-scale synchronization and resize observer.
5. `frontend/src/widgets/builtin/ChartWidget.tsx` — Full-featured chart widget with toolbar, indicator toggles, timeframe selector, and schema settings.
6. `frontend/src/widgets/builtin/index.ts` — Built-in registration of `chartDefinition`.
7. `frontend/src/chart/indicators.test.ts`, `sessionBreaks.test.ts`, and `ChartWidget.test.tsx` — Unit and integration tests.
8. `docs/qa/acceptance/F4.4.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Candlestick rendering and timeframe selection
- Chart loads OHLCV bar series and switches timeframes reactively without rendering artifacts.

### B2 — Multi-pane indicator parity
- Overlay indicators (SMA/EMA) overlay the price series while sub-pane indicators (RSI/MACD) render with aligned time-axes.

### B3 — Indian session break overlay
- Multi-day intraday series cleanly displays session break markers on day boundaries and 09:15 IST opening bars.
