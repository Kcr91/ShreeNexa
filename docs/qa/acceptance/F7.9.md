# F7.9 Acceptance Contract — 20-Level Depth Ladder, On-Demand 200-Level Book, and 5-Level Fallback

## Feature

20-level depth ladder and multi-script depth watchlist, on-demand 200-level full book with connection cost surfacing, and explicit 5-level fallback for unsupported segments (BSE/MCX/Currency).

## Scope decisions recorded before implementation

- **Depth Ladder Sizing and Capacity (Spec §3.3 & §12.5)**:
  - **20-level depth**: Standard depth ladder supporting up to 50 instruments per Dhan depth socket connection.
  - **200-level depth (On Demand)**: High-resolution full book for the single focused instrument. Consumes 1 entire dedicated depth socket connection. Surfaces connection cost explicitly in UI (`⚡ Dedicated Socket (1 instrument / connection)`).
- **Segment Limitation & Explicit 5-Level Fallback (Spec §3.3.2 & §12.5)**:
  - Full Market Depth (20/200 level) is supported only on `NSE_EQ` and `NSE_FNO`.
  - For `BSE_EQ`, `MCX_COMM`, `NSE_CURRENCY`, and `BSE_CURRENCY`, the broker/exchange only provides the 5 levels carried in the regular feed's Full packet.
  - The UI and API gracefully degrade to 5 levels and display an explicit explanatory banner (`ℹ️ 5-Level Depth Active: Exchange limitation (20/200 depth available only on NSE_EQ and NSE_FNO)`). Never renders an empty 20-level ladder.
- **Depth Watchlist Strip**:
  - Compact multi-script strip for up to 50 pinned instruments.
  - Surfaces Best Bid/Ask, Spread, Top-5 Imbalance Ratio, Total Book Size, and Depth Level Type.
- **Mathematical Invariants (Proof)**:
  - Cumulative quantities are strictly monotonic ($Q_{cum, i} = \sum_{j=1}^i Q_j \ge Q_{cum, i-1}$).
  - Book imbalance ratio is bounded: $\text{Imbalance} = (B_{total} - A_{total}) / (B_{total} + A_{total}) \in [-1.0, 1.0]$.
  - Golden depth packets tested and verified.

4. `backend/app/main.py` — Mount `depth_router`.
5. `backend/tests/unit/test_depth_book.py` — Backend unit tests for monotonic cumulative sums, 20/200/5 level sizing, fallback segment enforcement, and golden depth packets.
6. `frontend/src/depth/types.ts` — TypeScript models for depth levels, books, watchlist items, connection costs.
7. `frontend/src/depth/engine.ts` — Cumulative quantity calculation, imbalance calculation, segment capability detection.
8. `frontend/src/depth/engine.test.ts` — Mathematical tests for monotonic quantities, segment fallback, and imbalance bounds.
9. `frontend/src/widgets/builtin/MarketDepthWidget.tsx` — Depth Ladder & Watchlist widget with 20/200/5 levels, connection cost badge, and segment fallback banner.
10. `frontend/src/widgets/builtin/MarketDepthWidget.test.tsx` — Component tests for ladder rendering, monotonic cumulative quantities, on-demand 200-level mode, and 5-level BSE fallback.
11. `frontend/src/widgets/builtin/index.ts` — Register `marketDepthDefinition`.
12. `docs/qa/acceptance/F7.9.md` — Acceptance contract.
