# F4.8 Acceptance Contract — Backtest Analytics Visualizer Widget with Tear Sheet, Underwater Drawdown, and Monthly Heatmap

## Feature

Comprehensive backtest visualizer widget presenting institutional quantitative analytics: performance tear sheet scorecards (Sharpe, Sortino, CAGR, Max Drawdown, Win Rate, Profit Factor, Calmar), cumulative equity curve vs benchmark, drawdown underwater chart, monthly return calendar heatmap, and trade PnL distribution histogram.

## Scope decisions recorded before implementation

- **Key Quantitative Performance Metrics**:
  - Scorecard displays Sharpe ratio, Sortino ratio, CAGR %, Max Drawdown %, Max Drawdown duration, Win Rate %, Profit Factor, Expectancy, and overall Grade (A–F) derived from F3.10 scorecard model.
- **Visual Analytics Tabs**:
  - `Tear Sheet`: Metric scorecard grid with color-coded grade badges and risk-adjusted return ratios.
  - `Equity Curve`: Interactive performance curve comparing Strategy equity against benchmark (NIFTY 50).
  - `Underwater Chart`: Drawdown depth over time showing drawdown recovery windows.
  - `Monthly Heatmap`: Year-by-month return matrix with dynamic green-to-red intensity gradient and annual total returns.
  - `Trade Distribution`: Histogram of trade profit and loss distribution.
- **Widget Registry Integration**:
  - Registered in `widgetRegistry` under category `analytics`.

## Required deliverables

1. `frontend/src/analytics/types.ts` — Type definitions for scorecards, equity curve, monthly heatmap, and backtest reports.
2. `frontend/src/analytics/metrics.ts` — Metrics aggregation, drawdown curve calculation, and heatmap matrix transformations.
3. `frontend/src/widgets/builtin/BacktestAnalyticsWidget.tsx` — Visualizer component with tear sheet, equity curve, underwater chart, and monthly heatmap.
4. `frontend/src/widgets/builtin/index.ts` — Built-in registration of `backtestAnalyticsDefinition`.
5. `frontend/src/analytics/metrics.test.ts` and `BacktestAnalyticsWidget.test.tsx` — Unit tests.
6. `docs/qa/acceptance/F4.8.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Quantitative performance scorecard rendering
- Renders tear sheet scorecard with Sharpe, Sortino, CAGR, Max Drawdown, and overall strategy grade.

### B2 — Drawdown underwater chart and equity curve
- Computes underwater drawdown percentages matching peak-to-trough drops and displays strategy cumulative equity.

### B3 — Monthly returns heatmap matrix
- Renders Year x Month matrix with color-coded positive/negative return intensity tiles and full-year totals.
