# F5.1 Acceptance Contract — Product Runtime AIProvider Protocol and Boundary

## Feature

Product runtime `AIProvider` protocol, default `DisabledProvider`, deterministic `MockProvider`, prompt secret redaction engine, timeout enforcement, token/cost usage accounting, and pluggable real-provider boundary isolated from development Codex sessions.

## Scope decisions recorded before implementation

- **Separation of Concerns**:
  - Development Codex sessions in VS Code/CLI and product runtime AI are strictly separated.
  - The runtime backend never shells out to a developer interactive session or Codex environment.
- **Default Disabled State**:
  - Runtime AI is disabled by default via `DisabledProvider`.
  - System startup cleanly inspects and reports `disabled` status without crashing or throwing unhandled errors.
- **Strict Secret Redaction**:
  - All outgoing prompts and incoming payloads pass through an automated secret scrubber.
  - Redacts Dhan Client IDs, Bearer tokens, JWT tokens, private keys, passwords, and `.env` key-value pairs before dispatch.
- **Deterministic Mocking**:
  - `MockProvider` enables offline contract testing and generates schema-valid StrategyIR structures.
- **Usage Accounting & Timeout**:
  - Tracks total tokens, estimated cost (USD), latency (ms), and call counts.
  - Enforces configurable request timeout (`timeout_s`).

## Required deliverables

1. `backend/app/ai/protocol.py` — `AIProvider` protocol, `AIResult`, `ProviderStatus`, and custom exceptions.
2. `backend/app/ai/redaction.py` — Prompt and payload secret scrubber.

4. `backend/app/ai/disabled.py` — `DisabledProvider` default implementation.
5. `backend/app/ai/mock.py` — `MockProvider` with schema validation.
6. `backend/app/ai/factory.py` — Safe runtime provider factory.
7. `backend/app/ai/__init__.py` — Package exports.
8. `backend/tests/unit/test_ai_provider.py` — Comprehensive unit and contract tests.
9. `docs/qa/acceptance/F5.1.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Default disabled provider behavior
- Verifies system startup reports `disabled` status cleanly and calls to `generate_structured` raise `AIRuntimeDisabledError`.

### B2 — Mock provider contract and schema compliance
- Verifies `MockProvider` returns structured JSON adhering strictly to the requested schema (e.g. StrategyIR).

### B3 — Prompt secret redaction
- Injects simulated Dhan credentials, JWT tokens, private keys, and passwords into prompts; verifies they are redacted with `[REDACTED]` before provider execution.

### B4 — Timeout enforcement and usage accounting
- Verifies requests exceeding `timeout_s` raise `AITimeoutError` and valid calls record token counts and cost estimates in the accounting ledger.
