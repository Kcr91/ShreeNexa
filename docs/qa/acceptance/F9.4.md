# F9.4 Acceptance Contract — Reuse the Epic 3 Metric Registry for Forward-Test Results Without Calculation Forks

## Feature

Forward-testing (paper trading) results reuse the unified Epic 3 metric registry and strategy scorecard without calculation forks, code duplication, or divergence in performance analytics.

## Scope decisions recorded before implementation

- **Zero Calculation Forks (Spec §5.1, §10.8)**:
  - Metric calculations (CAGR, Sharpe, Sortino, Calmar, Max Drawdown %, Max Drawdown Value, Win Rate %, Profit Factor, Trade counts, Realized/Unrealized P&L) for forward test results must directly execute the authoritative Epic 3 calculation engine (`app.backtest.metrics`).
  - Scorecard evaluation, horizon profiles (Intraday, Swing, Positional, Investment), and deployment gates must directly execute `app.backtest.grading.evaluate_strategy_scorecard`.
  - No duplicate formulas or specialized "paper metrics" maths are permitted.
- **Canonical Adaptation**:
  - `app.paper.adapter`: Adapts paper trading state (`PaperAccount`, `PaperFill`, `PaperPosition`, and recorded `EquityPoint`s) from `PaperRepository` into the canonical `Portfolio` contract required by the metric registry.
- **Equity Snapshot Persistence**:
  - `PaperRepository` tracks time-series `EquityPoint` snapshots recorded across market updates or on-demand mark-to-market events, enabling accurate drawdown and daily return volatility calculations.
- **Parity Invariant & Proof**:
  - An independent trade/equity fixture (`backend/tests/fixtures/trade_equity_parity_fixture.json`) containing identical trade sequences and equity time points must produce bit-for-bit identical `BacktestPerformanceMetrics` and `StrategyScorecard` outputs across both Backtest mode and Paper Trading mode.
- **API Surface**:
  - `GET /api/v1/paper/metrics`: Returns `BacktestPerformanceMetrics` for the specified paper trading account.
  - `GET /api/v1/paper/scorecard`: Returns `StrategyScorecard` and deployment verdict for the forward-tested strategy.

## Required deliverables

1. `backend/app/paper/adapter.py` — Adapter transforming paper repository state into canonical `Portfolio` and exposing `calculate_paper_metrics` and `evaluate_paper_scorecard`.
2. `backend/app/paper/repository.py` — Extension to record and retrieve time-series `EquityPoint` snapshots.
3. `backend/app/api/paper.py` — REST endpoints for paper metrics and scorecard.
4. `backend/tests/fixtures/trade_equity_parity_fixture.json` — Standardized trade and equity fixture.
5. `backend/tests/unit/test_paper_metrics_registry_reuse.py` — Comprehensive unit test proving zero calculation fork, exact numeric parity between backtest and paper modes, and REST API integration.
6. `docs/qa/acceptance/F9.4.md` — Acceptance contract.
