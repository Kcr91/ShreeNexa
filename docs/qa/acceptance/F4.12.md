# F4.12 Acceptance Contract — Strategy Builder Visual Workspace with Block-Based IR Editor and Vector Backtest Runner Trigger

## Feature

Visual quantitative strategy builder allowing traders to construct technical indicator pipelines and conditional logic rules (Entry/Exit, Stop Loss, Take Profit), compiling them into valid StrategyIR JSON (conforming to F2.5 schema) and executing instant vector backtests with equity curves and performance scorecards.

## Scope decisions recorded before implementation

- **Block-Based Indicator & Rule Composition**:
  - Indicator Library: EMA, SMA, RSI, MACD, VWAP with parameter tuning (periods, source series).
  - Rule Blocks: `ENTRY_LONG`, `EXIT_LONG`, `ENTRY_SHORT`, `EXIT_SHORT` with `CROSS_ABOVE`, `CROSS_BELOW`, `>`, `<`, `==` operators and `AND`/`OR` combinators.
  - Risk parameters: Stop loss % and take profit % targets.
- **StrategyIR Compilation**:
  - Compiles visual tree directly into compliant `StrategyIRSchema` (version 1) matching backend F2.5 / F2.6 requirements.
  - Validates indicator dependency references before compilation.
- **Vector Backtest Execution Trigger**:
  - "Run Vector Backtest" button triggers the execution engine, producing cumulative return %, win rate %, trade counts, and mini equity curve.
- **Widget Registry Integration**:
  - Registered in `widgetRegistry` under category `analytics`.

## Required deliverables

1. `frontend/src/strategybuilder/types.ts` — Type definitions for indicators, rule blocks, and StrategyIR schema.
2. `frontend/src/strategybuilder/compiler.ts` — Visual-to-IR compiler, schema validator, and vector backtest simulation runner.
3. `frontend/src/widgets/builtin/StrategyBuilderWidget.tsx` — Block-based strategy editor component with live IR preview and runner trigger.
4. `frontend/src/widgets/builtin/index.ts` — Registration of `strategyBuilderDefinition`.
5. `frontend/src/strategybuilder/compiler.test.ts` and `StrategyBuilderWidget.test.tsx` — Unit tests.
6. `docs/qa/acceptance/F4.12.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Visual strategy composition and StrategyIR compilation
- Adding indicators and rules compiles to valid StrategyIR JSON with proper indicator mapping and signal definitions.

### B2 — Schema validation and error detection
- Disallows invalid rule references or missing operand indicators with descriptive validation errors.

### B3 — Vector backtest trigger and equity curve rendering
- Clicking "Run Vector Backtest" runs simulation and renders performance summary and equity curve.
