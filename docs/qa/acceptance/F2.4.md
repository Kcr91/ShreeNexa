# F2.4 Acceptance Contract — Compound Indicator Dependency Graph and Cycle Detector

## Feature

Compound indicator directed acyclic graph (DAG) dependency resolver, topological execution planner, and cycle detector for nested indicators and multi-expression strategies.

## Scope decisions recorded before implementation

- **Dependency Graph Structure**:
  - `IndicatorDependencyGraph` maintaining nodes (indicator/signal definitions) and directed edges (dependencies).
  - Explicit distinction between raw input inputs (`open`, `high`, `low`, `close`, `volume`) and derived indicator outputs.
- **Topological Resolution and Cycle Detection**:
  - Implementation of Kahn's topological sort algorithm guaranteeing deterministic execution ordering.
  - Identification and rejection of circular dependencies (e.g., $A \to B \to A$) raising `CyclicDependencyError` detailing the cyclic path.
- **Common Subexpression Elimination & Shared Node Evaluation**:
  - When multiple indicators/signals reference the same intermediate expression (e.g., `ema_20 = ema(close, 20)` used by multiple higher-level signals), the computation is executed once and shared across downstream nodes.
- **Execution Plan**:
  - `IndicatorExecutionPlan` executing the resolved DAG against a price/volume dataset and returning a dictionary of named series results.

## Required deliverables

1. `backend/app/indicators/graph.py` — `IndicatorDependencyGraph`, `IndicatorExecutionPlan`, `CyclicDependencyError`, `GraphError`.
2. `backend/app/indicators/__init__.py` — Package exports.
3. `docs/qa/acceptance/F2.4.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Directed acyclic graph construction & topological sort
- Resolves valid nested dependencies into the correct evaluation sequence.

### B2 — Circular dependency rejection
- Detects direct and indirect cycles and raises `CyclicDependencyError` with cycle details.

### B3 — Multi-node compound execution
- Successfully executes a graph of compound formulas (e.g. `sma20 = sma(close, 20)`, `rsi_sma = rsi(sma20, 14)`, `signal = crossover(rsi_sma, 50)`).

### B4 — Shared subexpression caching
- Reuses computed values for nodes referenced by multiple downstream formulas.
