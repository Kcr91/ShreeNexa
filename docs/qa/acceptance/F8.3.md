# F8.3 Acceptance Contract — Streaming Option-Chain Widget Combining Tick Prices/OI with Locally Computed IV/Greeks

## Feature

High-performance streaming option-chain widget with real-time WebSocket tick ingestion, 60 FPS requestAnimationFrame render-budgeting, local real-time Black-76 IV and Greeks calculation, stale-data and calibration-drift surfacing, and safe dynamic resubscription on underlying/expiry/strike transitions.

## Scope decisions recorded before implementation

- **Render-Budgeting & Tick Throttling (Spec §11.2 & §11.3)**:
  - Batch high-frequency tick updates across strikes and schedule DOM re-renders within a 16ms animation frame budget (60 FPS) to prevent UI thrashing under heavy tick bursts.
  - Price and OI flash animations highlight changes with decay.
- **Real-Time Local IV & Greeks Engine (Spec §11.2 & §11.3)**:
  - Continuously computes Black-76 IV and closed-form Greeks (Delta, Gamma, Theta, Vega, Rho) locally on incoming ticks using active calibrated convention parameters (`ForwardSource`, `DayCount`, `RiskFreeRate`).
  - Flags `is_iv_reliable = False` on near-zero vega or below-intrinsic contracts.
- **Staleness and Drift Visibility (Spec §11.2 & §11.4)**:
  - Integrates `DriftBadge` in the chain header with real-time drift status.
  - Surfaces visual stale-feed warning indicator when ticks are delayed (> 5s).
- **Subscription Lifecycle & Clean Resubscription (Spec §11.2)**:
  - Changing underlying, expiry date, or strike count safely un-subscribes previous contract security IDs and subscribes to new ones via the WebSocket feed manager without leaking subscriptions.
- **Dual-Sided Option Chain Presentation**:
  - Symmetrical Call / Put table with customizable Greek column visibility toggles (Delta, Gamma, Theta, Vega), straddle price, PCR ratio, and Max Pain.

## Required deliverables

1. `frontend/src/optionchain/useStreamingOptionChain.ts` — React hook managing WebSocket subscription lifecycle, tick buffering, render throttling, and local Black-76 Greeks calculation.
2. `frontend/src/widgets/builtin/OptionChainWidget.tsx` — Full-featured streaming option chain widget with column toggles, flash animations, and drift badge.
3. `frontend/src/optionchain/useStreamingOptionChain.test.ts` — Unit tests for render throttling, resubscription, and local Greeks updating.
4. `frontend/src/widgets/builtin/OptionChainWidget.test.tsx` — Unit tests verifying streaming rendering, column toggling, leg selection, and resubscription.
5. `docs/qa/acceptance/F8.3.md` — Acceptance contract.
