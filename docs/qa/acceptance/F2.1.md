# F2.1 Acceptance Contract — Vectorized Indicator Registry

## Feature

Vectorized technical indicator engine and extensible indicator registry organized in modular mathematical families (Trend, Momentum, Volatility, Volume, Statistical) with explicit warm-up tracking, deterministic NaN policies, and TA-Lib / pandas-ta reference parity.

## Scope decisions recorded before implementation

- **Standardized Indicator Interface & Architecture**:
  - `VectorIndicator` abstract base class defining `name`, `family`, `warmup_period(params)`, parameter validation, and vectorized computation over PyArrow Tables or numpy series.
  - Return type: single `np.ndarray` or structured dictionary of arrays (e.g. for MACD: `macd`, `signal`, `hist`; for Bollinger Bands: `upper`, `middle`, `lower`, `pct_b`).
- **Indicator Families & Primitives**:
  - **Trend**:
    - `SMA`: Simple Moving Average.
    - `EMA`: Exponential Moving Average ($\alpha = \frac{2}{n+1}$, SMA seed for initial bar).
    - `MACD`: Moving Average Convergence Divergence with configurable fast, slow, and signal periods.
    - `Supertrend`: ATR-based volatility trailing band with directional trend state ($+1/-1$).
  - **Momentum**:
    - `RSI`: Wilder's Smoothed Relative Strength Index ($[0, 100]$ bounded).
    - `Stochastic`: $\%K$ and $\%D$ smoothed momentum oscillators.
    - `ROC`: Rate of Change percentage.
  - **Volatility**:
    - `ATR`: Average True Range using Wilder's smoothing.
    - `Bollinger Bands`: Middle SMA $\pm k \times \text{StdDev}$ with Upper, Lower, $\%B$, and Bandwidth outputs.
  - **Volume**:
    - `OBV`: On-Balance Volume.
    - `VWAP`: Volume Weighted Average Price (intraday session anchored).
  - **Statistical**:
    - `Z-Score`: Standardized distance $(x - \mu) / \sigma$.
    - `Rolling Std`: Rolling standard deviation.
- **Warm-Up and NaN Policy**:
  - Every primitive declares exact `warmup_period`.
  - For indices $i < \text{warmup_period} - 1$, indicator output is deterministic `np.nan` (no look-ahead, no uninitialized garbage).
- **Parity Proof**:
  - Validated against independent reference dataset `backend/tests/fixtures/sample_indicators_reference.json` ensuring exact match to TA-Lib / pandas-ta mathematical standard.

## Required deliverables

1. `backend/app/indicators/registry.py` — `IndicatorRegistry`, `VectorIndicator`, `IndicatorFamily`, `IndicatorMetadata`.
2. `backend/app/indicators/primitives/` — Vectorized indicator family implementations (`trend.py`, `momentum.py`, `volatility.py`, `volume.py`, `statistical.py`).
3. `backend/app/indicators/__init__.py` — Package exports.
4. `docs/qa/acceptance/F2.1.md` — Acceptance contract.
5. `backend/tests/fixtures/sample_indicators_reference.json` — Mathematical reference fixture with known inputs and expected outputs.
6. `backend/tests/unit/test_vector_indicators.py` — Unit tests for registry discovery, parameter validation, warm-up NaN rules, and family calculations.

## Acceptance scenarios

### B1 — Indicator registry discovery and metadata
- All primitive indicators are registered upon import with unique identifiers, valid families, and documented parameter schemas.

### B2 — Mathematical parity against reference fixture
- Computations for SMA, EMA, MACD, RSI, Bollinger Bands, ATR, Supertrend, OBV, VWAP, and Z-score match reference values within $10^{-4}$ tolerance.

### B3 — Warm-up period and deterministic NaN policy
- Exactly `warmup_period - 1` leading bars are populated with `np.nan`; subsequent bars contain valid floating point numbers without look-ahead bias.

### B4 — Input schema flexibility
- Supports invocation with PyArrow Table, Python list/dict, or numpy array inputs.
