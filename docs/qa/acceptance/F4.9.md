# F4.9 Acceptance Contract — Live Dashboard Layout Manager with Templates, Export/Import JSON, and Workspace Hotkeys

## Feature

Advanced workspace dashboard management supporting pre-built trading templates (Day Trader, Options Desk, Quant Research), JSON layout serialization with export/import validation, and keyboard hotkeys (Alt+1...9, Alt+T, Alt+W, Alt+E) for rapid workspace navigation.

## Scope decisions recorded before implementation

- **Pre-Built Professional Templates**:
  - `Day Trader`: Integrated Chart, Watchlist, Market Clock, Order Ticket, and Blotter.
  - `Options Derivatives Desk`: Option Chain & Greeks, Multi-Leg Order Ticket, and Positions Blotter.
  - `Quant Research Lab`: Backtest Analytics Tear Sheet, Equity Curve, and Performance Scorecard.
- **Export and Import Schema Validation**:
  - Exports validated active `WorkspaceLayout` JSON.
  - Validates imported JSON structure against strict schema guard, rejecting malformed, corrupt, or missing tab definitions with explicit error messages.
- **Keyboard Hotkey Navigation**:
  - `Alt+1` through `Alt+9`: Instant switching to tab index.
  - `Alt+T`: Template modal trigger.
  - `Alt+W`: Widget palette launcher.
  - `Alt+E`: Export/Import modal launcher.
- **Persistent Storage Synchronization**:
  - Applying a template or importing JSON automatically updates `localStorage` and active context state.

7. `docs/qa/acceptance/F4.9.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Pre-built template loading
- Selecting "Options Desk" or "Day Trader" template replaces current workspace layout with curated widgets and saves to `localStorage`.

### B2 — Layout JSON export and import validation
- Exporting produces valid JSON string; importing valid JSON replaces workspace; importing invalid JSON is rejected with schema error.

### B3 — Hotkey workspace switching
- Pressing `Alt+1`, `Alt+2` switches active tab cleanly.
