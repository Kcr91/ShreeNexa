# F1.3 Acceptance Contract — Resumable Dhan 1-Minute Backfill in 90-Day Windows

## Feature

Resumable Dhan 1-minute intraday historical backfill chunked into 90-day windows, immutable raw ingest provenance, gap and duplicate detection reporting, deduplicated bar staging, and atomic publication to the warehouse.

## Scope decisions recorded before implementation

- **90-Day Window Slicing**:
  - Slices any broad historical date interval (up to 5 years) into strict non-overlapping `<= 90`-day query windows conforming to Dhan's intraday chart API constraints.
- **Resumable State & Checkpointing**:
  - `MinuteBackfillManager` maintains persistent/durable task checkpoint state so interrupted or killed jobs resume from the exact last incomplete 90-day window.
- **Deduplication & Kill-Resume Parity**:
  - Re-running or resuming a backfill guarantees zero duplicate bars in staged Parquet partitions or warehouse queries.
- **Immutable Raw Ingest Provenance**:
  - Raw JSON responses are saved under `data/raw/dhan/charts_intraday/<YYYY>/<MM>/<ingest_id>/payload.json` with redacted parameters.
- **Coverage, Gap, and Duplicate Quality Report**:
  - Generates a structured quality summary for each symbol: total bar count, date coverage range, detected timestamp gaps, and verified duplicate count (0).

## Required deliverables

1. `backend/app/worker/minute_backfill.py` — `MinuteBackfillManager`, 90-day window generator, checkpoint tracker, gap/duplicate analyzer, and warehouse promotion.
2. `backend/app/worker/__init__.py` — Worker exports.
3. `docs/qa/acceptance/F1.3.md` — Acceptance contract.
4. `backend/tests/unit/test_minute_backfill_windows.py` — Unit tests for 90-day window slicing, intraday candle parsing, and gap/duplicate reporting.
5. `backend/tests/integration/test_minute_backfill_resumable.py` — Integration tests for multi-window execution, kill/resume deduplication, raw ingest preservation, and DuckDB warehouse verification.

## Acceptance scenarios

### B1 — 90-day window slicing
- Given a multi-year date range (e.g. 2 years), splits the range into discrete windows where each window duration is `<= 90` days with continuous bounds.

### B2 — Intraday candle parsing
- Parses Dhan `/charts/intraday` payload arrays into typed 1m `BarRecord` instances with UTC timestamps and OHLCV fields.

### B3 — Kill and resume deduplication
- Simulates killing a multi-window backfill after window 1, then resuming; verifies no duplicate bars are inserted and final count matches expected total.

### B4 — Gap and duplicate reporting
- Runs quality report on backfilled symbols; confirms 0 duplicates detected and reports accurate coverage spans.

### B5 — Warehouse publication and DuckDB queries
- Promotes staged 1m bars into the active warehouse version and confirms queries via `WarehouseReader` return correct bar counts and timestamps.
