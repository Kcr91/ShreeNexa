# F3.14 Acceptance Contract — Monthly/Yearly/Rolling Returns and Continuous Mode Timeline

## Feature

Monthly, yearly, and rolling returns engine with interactive widget, and Continuous Mode Timeline seamlessly stitching Backtest -> Paper Trading -> Live Trading execution phases into an unbroken, non-overlapping performance timeline without double-counting.

## Scope decisions recorded before implementation

- **Compounded Return Matrix**:
  - Monthly returns formatted in Year x Month grid with year-to-date (YTD) compounded returns:
    $$R_{\text{year}} = \prod_{m=1}^{12} (1 + r_m) - 1$$
- **Rolling Returns**:
  - Rolling windows for 1-month (21 trading days), 3-month (63 days), 6-month (126 days), and 1-year (252 days).
  - Metrics: Minimum, Maximum, Median, Average, and Current rolling return.
- **Continuous Mode Timeline (Backtest -> Paper -> Live)**:
  - Three execution phases: `BACKTEST`, `PAPER`, `LIVE`.
  - Strict non-overlapping invariant: transition dates are strictly contiguous ($T_{\text{phase\_end}} < T_{\text{next\_phase\_start}}$) guaranteeing zero double-counting of any trading day or return.
  - Continuous equity chaining: equity bases are preserved across phase boundaries ($E_{\text{paper\_start}} = E_{\text{backtest\_end}}$, $E_{\text{live\_start}} = E_{\text{paper\_end}}$) yielding a continuous cumulative TWR.
- **Widget Integration**:
  - `ReturnsTimelineWidget` registered in `widgetRegistry` under category `analytics`.

## Required deliverables

1. `frontend/src/returns/types.ts` — Type definitions for execution phases, timeline slices, rolling returns, and monthly matrix.
2. `frontend/src/returns/engine.ts` — Compounded returns, rolling return calculator, and continuous mode timeline stitcher.
3. `frontend/src/widgets/builtin/ReturnsTimelineWidget.tsx` — Interactive widget with phase timeline view, monthly returns matrix, and rolling metrics.
4. `frontend/src/widgets/builtin/index.ts` — Registration of `returnsTimelineDefinition`.
5. `frontend/src/returns/engine.test.ts` and `ReturnsTimelineWidget.test.tsx` — Unit tests.
6. `docs/qa/acceptance/F3.14.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Independent compounded-return fixtures
- Verifies geometric compounding for monthly and yearly return calculations matches independent numerical fixtures.

### B2 — Rolling returns computation
- Verifies 21, 63, 126, and 252-day rolling returns correctly calculate min, max, median, and latest values.

### B3 — Continuous mode timeline zero double-counting
- Verifies Backtest -> Paper -> Live timeline joins adjacent phases without repeating dates or double-counting returns at boundary transitions.

### B4 — Widget rendering and UI interaction
- Verifies `ReturnsTimelineWidget` renders phase badges, monthly matrix table, rolling metrics, and is registered in `widgetRegistry`.
