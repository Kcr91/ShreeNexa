# F5.2 Acceptance Contract — Natural-Language to Schema-Constrained StrategyIR

## Feature

Compiles natural-language strategy descriptions into validated, schema-constrained `StrategyIR` drafts through the AI provider boundary. Enforces strict adversarial safety checks, automated repairs on malformed drafts, human-readable rule explanations, and draft-only status.

## Scope decisions recorded before implementation

- **Schema-Constrained Generation**:
  - Accepts natural-language strategy requirements (indicators, entry rules, exit rules, sizing, universes).
  - Emits canonical `StrategyIR` strictly conforming to the `app.strategy.ir.StrategyIR` schema.
  - Automatically enriches indicators (e.g. `EMA`, `SMA`, `RSI`, `SUPERTREND`, `MACD`, `BOLLINGER`) with validated parameter ranges.
- **Draft-Only Status & Adversarial Safety**:
  - Generated output is strictly marked with `draft_status="draft"`.
  - Prompts attempting to inject live execution commands ("place real orders", "bypass risk limits", "deploy immediately to Dhan", "disable kill switch") are safely sanitized and blocked from changing deployment state.
  - Runtime live trading state cannot be modified through the strategy generation API.
- **Repair Engine**:
  - Ingests malformed or incomplete strategy dictionaries (e.g. missing `schema_version`, omitted `ir_version`, raw strings for universe, missing indicators referenced in conditions).
  - Automatically fixes common defects, repairs indicators, normalizes compare nodes, and returns clean, validated `StrategyIR`.
- **Explanation Engine**:
  - Converts any `StrategyIR` back into structured, human-readable natural language explaining each entry rule, indicator condition, stop-loss, and sizing logic.
- **Representative Test Corpus**:
  - Validates at least 20 diverse representative trading strategy descriptions covering trend following, mean reversion, breakouts, momentum, multi-indicator combinations, and multi-timeframe models.
- **REST API Endpoints**:
  - `POST /api/v1/ai/generate-strategy`: Natural language to `StrategyIR` draft.
  - `POST /api/v1/ai/repair-strategy`: Repairs malformed strategy IR dictionaries.
  - `POST /api/v1/ai/explain-strategy`: Generates human-readable explanation of strategy rules.

## Required deliverables

1. `backend/app/ai/generator.py` — Core NLP prompt parsing, template expansion, StrategyIR compilation, and adversarial safety checks.
2. `backend/app/ai/repair.py` — Schema validation and structural repair engine.
3. `backend/app/ai/explainer.py` — Reverse rule explainer generating natural-language descriptions from `StrategyIR`.
4. `backend/app/api/ai.py` — REST API router exposing `/generate-strategy`, `/repair-strategy`, and `/explain-strategy`.
5. `backend/app/main.py` — Mount `/api/v1/ai` router.
6. `backend/tests/unit/test_ai_strategy_generator.py` — Comprehensive unit test suite with $\ge 20$ representative descriptions, adversarial prompts, repairs, and explanation roundtrips.
7. `docs/qa/acceptance/F5.2.md` — Acceptance contract.
