# F5.4 Acceptance Contract: One-Click Backtest from Approved Generated Draft

## Feature Definition
- **Feature ID**: F5.4
- **Name**: One-click backtest from an approved generated draft, preserving exact IR/version/provider metadata.
- **Dependencies**: F3.4, F4.8, F5.3
- **Proof Requirement**: Generated run equals a manual run with the same IR snapshot and configuration.

## Invariants & Acceptance Criteria

1. **AI Generation Metadata & Provenance**:
   - Every backtest executed from an approved AI-generated draft strategy must record an immutable `AIGenerationMetadata` block:
     - `prompt`: Original natural language prompt string used for generation.
     - `provider_name`: Identifier of the generating provider or model.
     - `model_version`: Semantic version string.
     - `ir_version`: Integer StrategyIR schema version.
     - `ir_hash`: Deterministic SHA-256 digest of the canonical StrategyIR snapshot.
     - `generated_at`: Timestamp of initial generation.
     - `approved_at`: Timestamp of user approval.
     - `draft_status`: Explicitly set to `"APPROVED_DRAFT"`.
   - Standard manual backtests omit this metadata (`ai_metadata is None`).

2. **Parity Proof Invariant**:
   - A backtest executed on an approved AI-generated draft yields identical results to a manual backtest run with the exact same StrategyIR snapshot and configuration parameters (`start_date`, `end_date`, `initial_cash`, `fill_timing`, `slippage_model`):
     - `metrics.total_return_pct` identical.
     - `metrics.win_rate_pct` identical.
     - `metrics.max_drawdown_pct` identical.
     - `metrics.total_trades` identical.
     - `metrics.sharpe_ratio` identical.
     - `trades` (fill events) identical in count, timing, side, and quantity.
     - `equity_curve` points identical.

3. **One-Click Execution & API Surface**:
   - Backend endpoint `POST /api/v1/ai/backtest-draft`:
     - Accepts `BacktestDraftRequest` containing `strategy_ir`, `prompt`, `provider_name`, and optional execution overrides (`start_date`, `end_date`, `initial_cash`).
     - Validates and deserializes StrategyIR.
     - Attaches validated `AIGenerationMetadata`.
     - Executes backtest runner and persists result into the durable backtest store.
     - Returns `BacktestDraftResponse` containing the assigned `backtest_id`, complete `BacktestResult`, and `ai_metadata`.

4. **Frontend One-Click Workflow**:
   - In `AIDraftModal.tsx`:
     - Surfaces "Approve & Run Backtest" action in addition to standalone approval.
     - Seamlessly applies the draft to the visual builder and initiates the backtest.
   - In `StrategyBuilderWidget.tsx`:
     - Displays the generated backtest card with clear AI provenance indicator (`AI Generated Draft` + IR hash).

5. **Quality & Boundary Compliance**:
   - Zero modifications to protected paths (`backend/app/engine/risk.py`, `backend/app/engine/broker.py`, `backend/app/dhan/orders.py`, `backend/tests/parity/`).
   - Zero live broker connections or credentials.
   - Full test coverage for parity and audit trail validation.
