# F6.4 Acceptance Contract — StrategySignal Nodes and Signal-Level And/Or/Not Composition

## Feature

StrategySignal composition nodes, cross-strategy signal resolution, cycle detection for recursive strategy graphs, topological execution order, and G1/G2 parity across composed strategies.

## Scope decisions recorded before implementation

- **Cycle Detection**:
  - Direct and indirect dependencies between strategies referenced via `StrategySignalNode` are modeled as a directed graph.
  - Any recursion (e.g. $A \to B \to A$ or self-reference $A \to A$) must be rejected at compilation/validation time with an explicit `StrategyGraphCycleError`.
- **Topological Sorting**:
  - Valid DAGs are topologically ordered so all producer strategies are evaluated before their consumer strategies.
- **Signal-level Boolean Composition**:
  - Consumer strategies can combine signals from multiple upstream strategies using standard IR logic: `AndNode`, `OrNode`, and `NotNode`.
- **G1/G2 Equivalence Across Composed Strategies**:
  - Vector evaluation (G1 via `VectorStrategyCompiler`) and incremental bar-by-bar evaluation (G2 via `IncrementalStrategyEngine`) must produce bit-for-bit identical entry and exit signal sequences on historical bars when composed across multiple strategies.

## Required deliverables

1. `backend/app/strategy/graph.py` — Strategy dependency graph builder, cycle detector, topological sorter, and composite graph runners for G1 and G2.
2. Updates to `backend/app/strategy/compiler.py` — Support `StrategySignalNode` with `external_signals` mapping.
3. Updates to `backend/app/strategy/incremental.py` — Support `StrategySignalNode` with `external_signals` mapping.
4. `backend/app/strategy/__init__.py` — Package exports for `StrategyGraph`, `StrategyGraphCycleError`, etc.
5. `backend/tests/unit/test_strategy_graph.py` — Comprehensive unit and parity tests.
6. `docs/qa/acceptance/F6.4.md` — Acceptance contract.

## Acceptance scenarios

### D1 — Cycle detection
- Builds a 2-node cycle ($A \to B \to A$) and a 3-node cycle ($A \to B \to C \to A$); verifies `StrategyGraphCycleError` is raised with full cycle trace.
- Builds a self-referencing strategy ($A \to A$); verifies cycle error.

### D2 — Topological execution order
- Given independent strategies $A$ and $B$, and consumer strategy $C$ depending on both, verifies evaluation order evaluates $A$ and $B$ before $C$.

### D3 — Boolean composition of strategy signals
- Strategy $C$ triggers when Strategy $A$ has entry AND NOT Strategy $B$ has exit.
- Verifies truth table semantics across all combinations.

### D4 — G1/G2 parity across composed strategies
- Runs a multi-strategy composed pipeline on a multi-bar price series.
- Verifies `signals_g1 == signals_g2` for all strategies and all bars without discrepancy.
