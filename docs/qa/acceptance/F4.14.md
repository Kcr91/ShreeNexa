# F4.14 Acceptance Contract — Integrated E2E Terminal Workflow

## Feature

End-to-end integration orchestrating the complete ShreeNexa terminal workflow: streaming market tick ingestion -> real-time indicator evaluation -> visual strategy rule trigger -> automated paper order execution -> blotter position update -> mark-to-market PnL reconciliation -> notification & alert dispatch.

## Scope decisions recorded before implementation

- **End-to-End Reactive Data Flow**:
  - Live tick stream (from F4.10 WebSocket feed) pushes new price points.
  - Streaming technical indicator engine (from F2.1/F4.4) calculates fast/slow EMA and RSI updates incrementally.
  - Visual strategy engine (from F4.12) evaluates active StrategyIR entry and exit rule blocks against indicator states.
  - Rule condition trigger generates automated paper order with margin verification (from F4.5).
  - Executed order updates Blotter positions table and real-time PnL blotter (from F4.6/F3.12).
  - Order fill chime and toast banner dispatch through Notification Manager (from F4.11).
- **Automated Verification**:
  - Full end-to-end integration test verifying that a synthetic tick sequence triggers golden cross condition, executes paper order, updates position blotter, and updates mark-to-market PnL.

## Required deliverables

1. `frontend/src/workflow/types.ts` — Type definitions for workflow events, pipeline steps, and terminal orchestrator state.
2. `frontend/src/workflow/engine.ts` — Real-time workflow engine connecting live ticks, indicator evaluation, StrategyIR triggers, and paper order generation.
3. `frontend/src/workflow/engine.test.ts` — Unit tests for workflow pipeline execution and indicator trigger evaluation.
4. `frontend/src/workflow/TerminalWorkflow.test.tsx` — End-to-end integration test verifying reactive terminal loop.
5. `docs/qa/acceptance/F4.14.md` — Acceptance contract.

## Acceptance scenarios

### B1 — Real-time tick ingestion to indicator updates
- Ingesting price ticks updates technical indicator state (fast EMA, slow EMA) incrementally.

### B2 — Strategy rule trigger to paper order generation
- When fast EMA crosses above slow EMA and RSI filter matches, generates automated BUY paper order with quantity and execution price.

### B3 — Blotter position and real-time PnL reconciliation
- Automated order updates Blotter position table and mark-to-market unrealized PnL is computed on subsequent ticks.
