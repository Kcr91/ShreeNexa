# Architecture Decision Records

Architecture decision records are immutable decision history. Accepted decisions are superseded by a later ADR rather than edited to hide the earlier choice.

## Status vocabulary

- **Proposed:** open for review and not yet binding.
- **Accepted:** binding for subsequent features.
- **Superseded:** replaced by a named later ADR.
- **Rejected:** considered and deliberately not selected.
